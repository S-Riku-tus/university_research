## D1 残差と周波数帯マスク

### 元runで直接確認できた範囲

元runには無雑音／−8 dB、3モデル各5秒の`group_occlusion_summary.csv`と、全1080秒に同じ帯域をゼロ置換した`group_mask_performance.csv`が保存されていた。30件をAの`source_wav_id, chunk_index`へ対応付け、各帯域のマスク前後で絶対誤差が増減したかを計算した。

- 対応は30/30件でラベル・予測が一致した。ただし保存された30件はすべて、統合二乗誤差がその秒の最良単体より大きい**失敗秒**だった。成功秒の深層マスク予測は元runに保存されていなかった。
- AlexNetの1–2 kHzゼロ置換は、無雑音でR² `.8910 → -15.1997`、−8 dBで`.8108 → -37.3618`へ悪化した。保存失敗秒でも10/10件の絶対誤差が悪化した。ONB見逃し数だけは減るがF1も低下しており、除去で予測が広く上方へずれた結果を「ONB改善」と扱えない。
- RFは2–5 kHzマスクで無雑音R²が`.8501 → .3881`、−8 dBが`.8599 → .4216`へ悪化した。その他の帯域の変化は小さく、PCA→RFがこの広帯域のゼロ置換に強く反応する。
- CNN＋Transformerでは−8 dBの256–512 Hzマスクだけが全体R²を`.7862 → .8827`、run-ONB 60秒RMSEを232.6→175.4 kW/m²へ改善した。しかし無雑音では同じマスクがR²を`.8986 → .8216`、近傍RMSEを92.0→127.7 kW/m²へ悪化させた。条件をまたぐ安定した改善ではない。
- マスク効果はモデル・条件・秒で方向が変わった。保存失敗秒についても、誤差を減らす帯域と増やす帯域は同じモデル内で一様ではなかった。

根拠表は[全240帯域効果](d1_sample_band_effects.csv)、[30秒の要約](d1_sample_summary.csv)、[全1080秒と保存5秒の対応](d1_band_alignment.csv)。

### 成功秒を補う再現runと採否

Aで固定した無雑音の代表成功秒`index=8.225704, chunk 54`と代表失敗秒`index=1.0, chunk 54`を明示して、元runと同じ条件の補完runを[`run_targeted_masks.py`](run_targeted_masks.py)で実行した。条件は[事前記録](../../configs/experiments/2026-09-22_d_targeted_masks.json)に保存した。

補完run出力は`Pool_boiling/.../regression_result/npy/ensemble/202609/22/d_targeted_m_xd-t0611-v0618_iw3-nm_s1e-9_e200_123340/`で、`completed.json`と3モデルの対象2秒×8帯域の出力を確認した。実行ログは[`targeted_no_noise.log`](targeted_no_noise.log)。

RF予測は両秒とも元runと完全一致した。成功秒では2–5 kHzマスクがRFの過小予測を2.15 kW/m²悪化させ、失敗秒では512–1000 Hz、1–2 kHz、2–5 kHzがRFの過大予測を6.83、7.78、6.75 kW/m²悪化させた。少なくともこのRF対では、帯域マスクは統合の成功を説明する改善要因にならない。

深層2モデルは同じseed・条件の再学習でも元runの予測を再現しなかった。代表成功秒でCNN＋Transformerは−77.17 kW/m²、AlexNetは−30.59 kW/m²、代表失敗秒で−57.72、−64.26 kW/m²ずれた。元の学習済み重みが保存されていないため、再学習モデルのマスク結果を元runの成功秒説明には採用しない。−8 dBの補完runは、同じ問題が繰り返されるため実行しなかった。[再現監査](d1_targeted_reproduction_audit.csv)、[採用できたRF結果](d1_targeted_accepted_band_effects.csv)。

**確認事実**：元runの失敗秒と全体帯域感度は対応できた。成功／失敗の同一秒比較はRFの無雑音代表対だけ完了し、深層2モデルは元runの重み未保存により完了不能だった。

**原因仮説**：AlexNet等の極端な変化には、その帯域の利用に加えて、raw-powerを0へ置くことで学習分布外の入力を作った影響が含まれる。条件ごとに符号が変わるCNN＋Transformerの低域効果は、固定した物理帯域価値よりmatchedノイズ学習への依存を示す候補である。

**次の識別比較**：新しい主runでは学習済みモデル、全評価秒の帯域別予測、再現設定を同時保存する。既存run151715の深層成功秒だけを再構成するための追加再学習は行わない。

## D2 説明性手法の信頼性判定

| モデル・手法 | 点検結果 | 修論・発表での扱い |
|---|---|---|
| RF / TreeSHAP | 無雑音・−8 dBの計10秒すべてで予測を再構成。最大絶対誤差0.523 W/m² | RF内部でPCA成分が予測をどう組み立てたかに使用可。PCA成分をHz帯や気泡音へ読み替えない |
| CNN＋Transformer / IG | 無雑音1/5、−8 dB4/5だけ収束。0 raw-power baseline以外は保存なし | 主張から地図を外す。数値収束済み例もbaseline感度未確認のため付録候補に限定 |
| AlexNet / IG | 無雑音0/5、−8 dB2/5だけ収束。0 raw-power baseline以外は保存なし | 主張から地図を外す |
| AlexNet / Grad-CAM | 10/10配列は有限で0〜1。実装は最終Conv2D `alex_conv5`の12×12地図を224×224へ補間し、ReLU後の正方向だけを画像ごとに正規化 | 広い正方向反応位置の補助図に限定。符号付き誤差、細い帯域、寄与量、物理的気泡位置の根拠にしない |

IGは数値積分のcompletenessだけでなく、代替baselineの結果がないためD2のbaseline感度に合格していない。再学習せずに別baselineを計算できる保存モデルもない。この不足を図の解釈で補わない。Grad-CAMは粗さが帯域判断を妨げるが、D1の共通マスクですでに帯域候補を採用しない判断ができるため、Grad-CAM++等の追加比較は行わない。別CAMの見た目が変わっても現在の入力改善判断は変わらない。

根拠は[TreeSHAP監査](d2_treeshap_audit.csv)、[IG監査](d2_ig_audit.csv)、[Grad-CAM監査](d2_gradcam_audit.csv)、[手法判定表](d2_method_decision.csv)。

## D3 入力改善・再学習へ進むか

現時点では特定帯域の保持・除去再学習へ進まない。

1. 全モデル・無雑音／−8 dBで誤差を安定して減らす帯域がない。
2. −8 dBのCNN＋Transformer 256–512 Hz除去は改善したが、無雑音で逆方向に悪化した。
3. AlexNet 1–2 kHz等の巨大な変化は有用帯域の存在を示す一方、ゼロ置換による大きな分布変化も含み、除去すべき帯域とは解釈できない。
4. 元runの深層成功秒を再現できず、帯域感度と統合成功の対応を両側で確認できない。

帯域仮説を今後採用する条件は、(a) 学習済みモデルを保存した新runで成功・失敗秒を同じモデルへ対応、(b) 同幅の対照帯域と0以外の学習分布内置換で方向が維持、(c) 複数seed・無雑音／雑音で回帰全域とONB近傍を同時に悪化させない、の3点である。満たした場合だけ帯域保持／除去後の再学習へ進む。同期映像がないため、成立しても「その帯域が物理的な気泡音」とは断定しない。

## D1〜D3の結論

説明性について得られた明確な示唆は、単一の有用帯域の発見ではなく、**帯域感度がモデル・ノイズ条件・秒に依存し、ゼロ置換の極端な予測シフトを含む**ことである。TreeSHAPはRF内部の数値説明に残し、IGは主張から外し、Grad-CAMは粗い補助図へ限定する。現段階では帯域加工モデルを追加せず、結果と限界を修論の第6章へ記述する。
