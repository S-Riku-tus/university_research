## 次工程の提案（未実行・本人の確定方針とは区別）

### 1. 最優先：選別効果と再現性を同じ比較で確かめる

今回のスライドと直結する22 kHz・無雑音・200 epochs・6/11学習→6/18全1080秒評価を基準にする。選別なし／ありを同じ3 seedsで比較し、各対でデータ分割、モデル、前処理、重み決定方法を固定する。まず3 seedsは傾向を確認する規模であり、有意性を保証しない。以前の3 kHz・300 epochs案は過去時点の提案で、今回の基準条件に自動適用しない。

R²・MAE、ONB近傍誤差、熱流束ごとの誤差、重みを保存する。同じ200 epochsでも選別で学習更新回数は変わるため記録する。改善が再現するか、除外した弱い音の領域で悪化しないかを判断する。選別の利点が見えた場合にだけ、同数をランダム除外する対照で音響基準自体の効果と標本数減少を識別する。7/9追加・閾値探索を同時に混ぜない。

### 2. 既存予測で先に進める：統合の成功・失敗を誤差から説明する

22 kHz無雑音の改善条件と−8 dBの単体負け条件を主な対比候補にする。元WAV/熱流束別に、各モデルの誤差の方向、同時に外すか、重みに対して誤差がどう合成されるかを調べる。保存予測の等重み平均も比較できる。重みの学習はテスト成績を用いない。

同方向の誤差を共有するなら平均化の利点が小さい。学習内で最良だったモデルが別日で悪化するなら重みの転送が課題。等重みが現行重みを上回るなら、まず重みの偏り・安定性を調べる。これらの事実から必要性を判断し、既存方式で識別できない場合に新方式を検討する。説明画像の違いだけで誤差補完を証明しない。

### 3. 中心仮説：固定モデルの耐雑音性

処理条件を固定後、まず22 kHzでclean_onlyを確認する。学習済みモデル、PCA、scaler、統合重みを固定し、評価側の雑音のみを変える。既存matchedとの違いを読む。必要に応じ3 kHzへ拡張する。強雑音時の絶対性能と無雑音からの劣化量の両方で単体と統合を比べる。条件範囲を最初から35条件以上へ拡大しない。

### 4. 説明性を、原因の識別に使う

成功／失敗の代表条件で、周波数帯マスクと誤差の変化を対応させる。帯域幅の違いとゼロ置換による不自然な入力を考慮し、必要な帯域のみ同じ幅の対照・背景値置換・除去後再学習等で検証する。マスク直後の性能崩壊だけでは、その帯域に物理的に有用な情報があると断定できない。IGは少数の同一試料で数値収束と安定性を確かめ、手法数を増やすことを主目的にしない。

### 5. 独立検証と計測準備は並行して始める

6/18を繰り返し参照して得た改善は原因診断として扱う。新しい独立日のデータで、設定を固定した後の性能を確認する機会を確保する。ONB発生検知まで結論するなら、音響に同期した気泡観測等の独立な正解、ONB前後の熱流束刻み、反復、録音条件を計画する。最終評価用データの設計を今から進め、既存データの全解析完了を待たない。
