従来performance比では無雑音21.96%、−20で10.76%の全域RMSE低減。MSE元3比では18.40%、7.28%の低減。5の全域R²は0.9894→0.9225へ悪化し、全域RMSEは雑音増加に対し単調増加している。

[全11方式の主指標](pooled_metrics.csv)、[端点の全方式](endpoint_comparison.csv)、[比較相手別の差・誤り訂正](five_vs_baselines.csv)。ET単体と5等重みには全7条件で全域RMSEが小さい。最良単体を評価後に確認すると、無雑音〜−16の6条件はET、−20はHGBで、5は前6条件では最良単体より小さく、−20ではHGB74.19に対し5が75.23。これは事後的な記述比較で、最良単体を事前選択した運用性能ではない。

## 6. 統合が何を補っているか

5の保存重みは元3ブロック25%、HGB27.25%、ET47.75%。個別ではRF1.46%、Conformer17.83%、AlexNet5.71%、HGB27.25%、ET47.75%。全7雑音で固定されており、入力を見て重みを切り替えた結果ではない。[重み](weights.csv)。

MSE元3→5を領域別に分けると、無雑音は近傍39.58→16.45・ONB以上38.28→26.49を改善し、ONB前27.10→29.54は悪化。−20はONB前102.01→94.29・ONB以上62.07→57.89を改善し、近傍93.92→99.32は悪化する。近傍はONB以上と重なるため、この3領域の誤差を独立に加算しない。[領域別の損失変化](regional_loss_changes.csv)。

元3/HGB/ETの3ブロックに分けた残差では、−20の全体MSE減少の87.15%が3ブロック同方向誤差の標本群から生じた。逆符号の相殺だけでなく、同方向でも誤差の小さい予測へ調整した効果が大きい。[方向群の寄与](error_direction_contributions.csv)。これは保存予測の代数的な損失分解で、音響特徴や物理音源の因果寄与率ではない。以前の接続分析と同じ数値が今回runでも確認された。
