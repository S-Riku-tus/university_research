# 3 kHz日内holdout・clean_only／matched比較

記録日: 2026-09-29。6/11・6/18それぞれについて、同一日の元WAVを学習13本・外側テスト5本へ固定分離し、`clean_only`と`matched`を比較した。評価単位は1秒chunkだが、独立な実験単位は元WAVである。

## 結論

4 run・28条件はすべて完了し、比較条件も揃っていた。両日とも方針間で外側テストWAVは同一で、clean条件の全モデル・両統合予測は最大絶対差0だった。`clean_only`は7 noiseで1 fitを共有し、`matched`は7 noiseで7 fitを持つ。

主要結果は次のとおり。

1. `matched`の全域RMSEへの効果は日依存だった。`performance_kfold`のnoise 6条件平均は、6/11で50.76→50.22 kW/m²とほぼ同等、6/18で73.25→64.97 kW/m²と8.28 kW/m²改善した。
2. 6/18の改善を「全熱流束域の改善」とは呼べない。−20 dBでは全域RMSEが110.36→81.33へ改善した一方、ONB近傍RMSEは21.04→146.13、ONB以上RMSEは32.64→90.78 kW/m²へ悪化した。改善は主に58.39 kW/m²の最低熱流束WAVのRMSEが219.80→35.44へ低下したためである。
3. 6/18の強noiseで`matched`はONB前の過大予測を除き、FPRとF1、連続ROC-AUCを改善した。ただしONB近傍の連続値と高熱流束側を低く外した。全域回帰、固定閾値判定、ONB近傍回帰で評価が分かれる。
4. `performance_kfold`固有の優位はまだ確認できない。matchedのnoise平均では両日とも等重みが僅かに良く、6/18 matchedでは内部最大重みモデルと外側最良単体が0/7一致、順位相関平均は−.571だった。
5. 6/11テストにはONB±10%のWAVがない。多くの条件でFPR=FNR=0でも、57.59・181.38 kW/m²と427.28 kW/m²の間に大きなラベル間隔があるため、ONB近傍性能が良い証拠にはしない。

## アンサンブル重み

| run | performanceが最良単体に勝利 | 等重みが最良単体に勝利 | 内部最大重み＝外側最良 | 内部・外側順位相関 | performance−等重みRMSE |
|---|---:|---:|---:|---:|---:|
| 6/11 clean_only | 1/7 | 1/7 | 6/7 | .929 | −1.04 |
| 6/11 matched | 5/7 | 4/7 | 3/7 | .143 | +0.10 |
| 6/18 clean_only | 2/7 | 2/7 | 3/7 | .714 | −0.05 |
| 6/18 matched | 3/7 | 3/7 | 0/7 | −.571 | +0.40 |

6/11 matchedでは内部順位の一致が低くても統合が最良単体を上回った。これは重み順位の正しさより、外側での正負biasや残差の相殺と整合する。一方、6/18 matchedでは内部順位が逆向きで、等重みが平均で僅かに良かった。パラメータ変更後に再判定する本人方針を維持するが、現結果だけから「性能重みが等重みより有効」とは言えない。

## 別日結果との接続

既存の3 kHz別日比較では、performanceのnoise平均RMSEが6/11学習→6/18評価でclean_only 92.6→matched 97.5と悪化し、6/18学習→6/11評価で93.8→76.2と改善した。今回の日内では6/11が50.8→50.2とほぼ同等、6/18が73.2→65.0と改善した。

この対応から、matchedの利得は「評価日がどの日か」または「日付をまたいだか」だけでは説明できず、**6/18を学習元にしたときに強く現れる**。6/18のnoise下入力と熱流束の対応、特に低熱流束側の過大予測をnoise別学習が修正している可能性がある。ただし、同じ水流素材を加えたnoiseであり、独立noiseへの一般化は未確認である。

## 確認事実・仮説・次の識別比較

### 確認した事実

- 分割・clean再現・fit共有範囲は意図どおりで、比較可能である。
- 6/18 matchedは全域RMSEと強noiseの誤報を改善したが、ONB近傍・以上の連続値は悪化した。
- 6/11 matchedの全域利得は小さい。
- 6/18 matchedの全域利得は最低熱流束WAVへ集中した。
- `performance_kfold`は等重みを安定して上回っていない。

### 整合する仮説

- 6/18のclean学習モデルは強noiseで低熱流束を大きく過大予測し、matchedがこの日固有の校正ずれを学習した。
- 強noiseのmatchedモデルは高熱流束情報を十分保持できず、予測を低い側へ縮めたため、低熱流束RMSEとFPRは改善する一方、ONB近傍・以上を過小予測した。
- matched統合の一部改善は、内部重み順位の正しさではなく単体biasの相殺による。

入力帯域の因果的利用や物理現象は、この結果だけでは確定しない。

## 次に行うこと

> **同日再整理**：`test_split_seed=43,44`の現行holdoutは未実施だが、旧日内GroupKFoldが全WAVを評価側へ回しており、目的が重なる。追加splitを直近優先から外し、[現在の問題定義と次の改善対象](../../docs/research_plan/2026-09-29_problem_definition_and_next_priority.md)を後継方針とする。

### 1. 主問題を固定する

修士研究の主問題としては、cleanで学習した固定モデルの未知noise耐性を扱う`clean_only`を主、SNRごとに別モデルを学習する`matched`を既知noise適応の診断対照とする案を推奨する。改善対象はstrong noiseの全域RMSE・低熱流束の正bias・FPRであり、ONB近傍・ONB以上・Recallを同時に確認する。

### 2. 学習側限定のチューニングを行う

既存計画の小規模18候補を学習側WAVの内部OOFだけで選ぶ。外側テストの`ensemble_presentation_summary.csv`を候補選択に使わない。目的は、継承した現パラメータが単体モデルとperformance重みを不利にしていないかの確認である。現データではONB近傍WAVが各日1本しかないため、現在の外側ONB結果を見て合成係数を後付けしない。

### 3. パラメータ固定後に学習乱数を確認する

選択パラメータを固定して`run.seed=43,44`を追加する。このとき`test_split_seed=42`は固定し、分割不確かさと学習不確かさを混ぜない。

### 4. 必要な場合だけ外側splitを追加する

改善案を固定した後も結論が最低熱流束1 WAVに依存する場合に限り、`test_split_seed=43,44`または現行条件での外側WAV K-foldを追加する。現パラメータのまま全7 noiseを繰り返す作業は直近優先にしない。

### 5. 説明性・帯域摂動へ進む

方針とモデルを固定後、6/18の58.39 kW/m²と271.68 kW/m²を優先し、clean／−16／−20 dBで2.1–2.5 kHz帯と隣接同幅帯域の遮蔽を比較する。低熱流束の修正とONB付近の悪化が同じ帯域依存で生じるかを識別してからIG等の説明画像へ接続する。

## 限界

- 外側holdoutはseed 42の1分割だけで、各熱流束は1 WAVに対応する。300 chunksを300独立実験とは数えない。
- 6/11にはONB近傍テストがなく、6/18の近傍評価も1 WAVだけである。
- noiseは同じ生成仕様・素材分布に対応する。独立水流noiseや新規収録への一般化は示していない。
- matchedはSNRごとの別モデルであり、同一モデルのnoise耐性を表すのはclean_onlyである。
- 最良単体は外側結果から事後選択した記述比較であり、運用時に既知のモデル選択ではない。
