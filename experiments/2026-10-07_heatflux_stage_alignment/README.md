# 熱流束の段階対応・時間幅の修正と比較

**後続更新**：本人の実行後、[従来階層への修正と内容確認](../2026-10-07_heatflux_result_layout/README.md)を実施した。以下は当初の比較記録。現在は追加階層を廃止し、生成済みCSVは従来の結果直下で改名/STFT/ONBから読める。再実行前の保護はexperimentsへの退避で行う。

2026-10-07。本人の「既存データを崩さない範囲で方針どおり進める」という指示に基づく。通常の入口は既存の`0.run_auto_heatflux_analysis_v2.ipynb`のまま。音響生成・改名の実行・モデル学習は行っていない。

## 確認事実と今回だけ停止した理由

- 本人が保存した新実験debugは、独立抽出したシャント23段階・電極21段階。特に同じ電極電圧段階内でシャントの安定領域が分断され、別々の抽出では平均の対応が失われる。過去debugの同数は、常に同じ時刻を抽出できていた証明ではない。
- 新GL860は1秒間隔、比較した旧6/18は約5秒間隔。同じ8点でも先頭から末尾の時間幅は7秒と約35秒。今回の方が短い揺らぎや区間の分断を抽出しやすい。計測器変更による量子化・雑音の寄与割合までは分離していない。
- 両電圧の共通8点窓だけにすると新実験は35区間になる。安定区間数を印加電圧段階数と見なすことはできない。
- 旧6/18の保存ラベルは`0, .1, .3, .5, .7, .8, …, 2.0 V`。段階数に0.1を掛ける対応は過去実験にも不適切。

## 採用した方法

1. 原ロガーの時刻・スキャン番号を保持して読み、GL860のCH2[mV]をVへ変換する。水温条件で行を詰めない。
2. 電極電圧の持続的な上昇から段階境界を検出する。5秒の中央値処理、0.04 V以上の変化、5秒の持続確認を使い、一時的な立ち上がりの突出を段階と数えない。持続的な下降は終了境界とする。検出境界は保存する。
3. 印加電圧の値は[処理config](../../configs/datasets/2026.10.07_0.3_1_heatflux_processing.json)の明示リストで対応させる。今回は0.0～2.0 Vの21段階。録音名とノートが1.0～2.0 Vを裏付け、低電圧側の0.1刻みはロガーの等間隔の上昇と整合する設定であり、独立した操作履歴の証明ではない。段階数が一致しなければ停止する。
4. 各通電段階の切替後5秒を除き、水温80±1 ℃、シャント>0.001 Vを維持。35秒窓の両標準偏差が従来閾値（1e-4 V、1e-3 V）未満の共通区間を抽出する。温度条件外の時刻や欠測をまたいで結合しない。
5. 同一段階内で安定窓が重なる連続領域のうち、最長の領域を1組の代表平均にする。同時間長の候補は先の候補を採る。窓単位の安定条件なので、長い採用領域全体の標準偏差も別途保存する。成立しない段階を除いたり、基準を緩めたり、ラベルを補間したりしない。
6. 熱流束は従来の`mean(shunt)/R_shunt * mean(Pt)/(π d L)`、単位W/m²を保持する。区間・採用率・段階全体との平均差・瞬時積平均との差を保存する。無通電の微小オフセットから抵抗を推定せず、0 Vの温度は水温とする。通電段階の温度式は保持した。

音響や学習精度・ONB指標を見て抽出条件を選んでいない。35秒は旧8点窓の時間幅を基準にした。15・35・55秒だけの感度比較を実施した。

## 比較結果

評価単位は印加電圧段階。無通電のほぼゼロのqは相対差の集計から除いた。

| 比較 | 確認結果 |
|---|---|
| 新実験・35秒 | 21段階が成立。録音11本すべてが1.0～2.0 VのCSV行に対応 |
| 旧6/18・35秒 | 非等間隔の18段階が成立。保存済みqとの差は最大0.1581%、観察ONBの1.1 Vでは−0.0187% |
| 新実験・15秒対35秒 | 熱流束差は最大0.2210%。1.2 Vは329.640対330.370 kW/m² |
| 新実験・55秒 | 1.1 Vで成立せず。基準を緩めず失敗として記録 |
| 旧6/18・55秒 | 0 Vで成立せず。60秒の基準区間内で水温条件を満たす部分が約50秒 |
| 新実験・採用区間対段階全体 | 切替直後・水温条件外を除いた段階全体に対し、qの差は最大2.125%（0.1 V）。録音対象1.0～2.0 Vでは最大約0.490% |
| 新実験・採用率 | 条件を満たす段階内の点数に対して約51.7～100%。採用外の点を測定不良とは断定しない |
| 新実験・平均の積対瞬時積の平均 | 差は最大約0.000512%。主ラベルの定義は変更しない |
| 既存Notebook | 熱流束・温度・沸騰曲線・共振周波数のセル1～8を、別保存先で完走 |
| 関連自動チェック | 52件成功。両チャンネルの同じ行、記録間隔、欠測・温度逸脱、段階抜け、単位変換、版の共通参照、旧ONB値保持など |

新実験は本人の現在の`R_shunt=0.001667 Ω`、d=0.0003 m、L=0.03827 mで比較した。旧実験は元コードのd=0.0003 m、L=0.03954 m、R_shunt=0.001667 Ωを使った。今回の抵抗の実物値は当初未確定との回答であり、設定値の検算と計測校正は区別する。qはR_shuntに反比例する。

自動直線性喪失候補は今回約275.7 kW/m²（1.1 V）だった。ノートの沸騰開始1.2 Vとは別であり、ONB登録はノートの観察を維持する。現設定で1.2 Vのqは330.370 kW/m²だが、装置条件を含めた確定値とは呼ばない。
