# 保存結果による誤り補完と特徴利用の接続

記録日：2026-10-14。本人が許可した「現状ある情報で、既存結果を説明へつなぐ分析」に対応。元2025年の保存予測と、完了済み入力加工・入力除去実験の指標を使用した。新学習・モデル推論・新入力加工は0。自動重み切替の実装、2026年新実験、修論完成後の最終確認は対象外。

- 2025/6/11＋6/18、既知36 WAVの未使用540 chunk、1秒・3 kHz、選別なし、within_wav_chunk＋clean_only。
- 元run：`onb_wc-t0611-v0611_ic3-nc_c1s_s0_e200_193305`、seed42、CNN200 epochs。比較相手は元3 MSE統合、HGB4、ET4、ET単体。5は元3＋HGB＋ET。
- 日別ONB：6/11＝221.5051102、6/18＝271.6776816 kW/m²。ONB前225、ONB±10%近傍30、高q側285。この集合の近傍30はONB以上側だけなので、3領域は非重複。
- 高q側は日別ONB±10%の上側を超える領域。旧主表の`rmse_high`はONB以上全体を含むため、同じ名前の数値として混ぜない。
- chunkは評価標本で、540回の独立した沸騰実験ではない。追加seed・新しい独立録音評価ではない。
- 全7雑音の評価ID、保存重みからの再構成、主表のRMSE/FN/FPとの一致、112損失分解の恒等式を検算。[条件・出典hash・検算](verification.json)。全出典は不変。

再解析：`python experiments/2026-10-14_error_feature_linkage/analyze_saved_evidence.py`

## 1. 改善する領域は雑音で変わる

以下は全てRMSE、単位kW/m²。いずれも同じ540標本内の元3→5。

| 評価領域 | 標本数 | 無雑音：元3→5 | −20 dB：元3→5 |
|---|---:|---:|---:|
| 全体 | 540 | 34.07→27.80 | 81.14→75.23 |
| ONB前 | 225 | 27.10→29.54 | 102.01→94.29 |
| ONB近傍 | 30 | 39.58→16.45 | 93.92→99.32 |
| 高熱流束側 | 285 | 38.14→27.33 | 57.70→51.63 |

確認事実：無雑音は近傍・高qが改善しONB前は悪化、−20はONB前・高qが改善し近傍は悪化。無雑音で382/540、−20で357/540標本の二乗誤差が減った。全域の改善を全領域・全標本の改善としない。

解釈：全域MSE目的の統合は、平均的な利得を得ながら領域ごとの交換を伴う。この結果は統合目的と検知目的の違いを説明する根拠となるが、今から近傍目的へ切り替える必須指示ではない。詳細な境界救済を新課題へ追加しない。

## 2. 逆符号の相殺だけでは補完を説明できない

実際に追加統合している3ブロック（元3の固定予測・HGB・ET）について、真値を挟む逆符号の誤差がある標本と、3ブロック全てが同方向に外れる標本に分けた。五つの単体全ての符号分類ではない。

| 条件 | 3ブロック誤差 | 標本数 | 改善標本数 | 全体MSE減少への寄与 | 全体減少に占める割合 |
|---|---|---:|---:|---:|---:|
| 無雑音 | 逆符号を含む | 211 | 178 | 175.88 | 45.35% |
| 無雑音 | 同方向 | 329 | 204 | 211.97 | 54.65% |
| −20 dB | 逆符号を含む | 112 | 86 | 118.61 | 12.85% |
| −20 dB | 同方向 | 428 | 271 | 804.44 | 87.15% |

寄与の単位は(kW/m²)²。各群の二乗誤差の総減少を全540で割り、加算すると全体MSE減少になる。群内だけのMSE改善率や、因果寄与率ではない。

確認事実：−20の改善の大部分は同方向誤差の標本群から生じた。現在の有用な補完は、過大/過小の相殺だけでなく、同方向でも誤差の小さい予測へ調整することで得られる。単なる残差相関の低さ、逆符号の頻度、モデル数だけでは効果を説明できない。

残差分解は、元3誤差をe、5−元3の調整をδとすると、MSE差＝2平均(eδ)＋平均(δ²)。無雑音は−851.94＋464.09＝−387.85、−20は−1346.86＋423.81＝−923.05。誤差を減らす方向への調整が、調整の二乗項を上回った。[分解](regional_loss_decomposition.csv)、[方向群](error_direction_contributions.csv)。これは保存予測の恒等式による説明で、音響の物理機構の証明ではない。

## 3. 4→5も条件によって追加効果が変わる

ET4→5のMSE差は無雑音＋24.94（悪化）、−20は−132.91（改善）。このrunでは、5−ET4＝0.272464×(HGB−ET)という保存配分による調整で説明できる。

無雑音は誤差との調整積＋3.96と調整の二乗＋20.98が共に悪化に寄与。−20は調整積−159.03が二乗＋26.12を上回り改善。モデルを一つ増やした事実だけでなく、その出力が基準の誤りをどちらへ動かすかで効果が変わる。

−20のET4→5は改善268、悪化272標本でも全体MSEは減った。改善標本の件数だけでなく、その誤差量が必要になる。全方式・全指標で5が勝つことは必須条件にしない。

## 4. 特徴利用との差をどこまで接続できるか

入力依存の数値は、新しい加工や推論ではなく[10/7の完了済み対照](../2026-10-07_onb_input_and_integration/README.md)を再利用した。

| 無雑音の時間行並べ替え | 元RMSE→加工後RMSE |
|---|---:|
| CNN＋Transformer | 35.34→47.99 |
| AlexNet | 39.88→56.45 |
| HGB | 33.25→33.25 |
| ET | 28.40→28.40 |
| 元3 | 34.07→47.52 |
| 5 | 27.80→31.10 |

確認事実：CNN系は時間配置変更で変わるが、HGB/ETの34要約特徴・予測は不変。集計により時間順序を失う構造と一致する。異なる入力依存を持つモデル群を組み合わせている根拠がある。

同時に、全体power2倍ではHGB33.25→71.33、ET28.40→76.58へ悪化し、2.1–2.5 kHzのpower0.1倍ではHGB147.97、ET133.15。要約モデルが全ての入力変化に頑健とはいえない。5も全体gain・対象帯域加工で悪化する。

完了済みの入力除去後再学習では、HGB/ETいずれも全34特徴が絶対強度のみ5特徴、相対形状等29特徴より全域回帰に良かった。強度と形状を併用する入力が現在の精度を支える。ただし固定モデルへの入力加工と、入力除去後の再学習は別の検証。

**現在説明できる結論**：モデル群の入力依存には実際の違いがあり、統合で予測を調整すると領域別の誤差が変わる。雑音時の全域改善は、逆符号相殺と同方向誤差縮小の両方から生じ、元3/4/5で交換がある。

**未確定**：時間配置への依存の違いが水流雑音時の改善をどれだけ生んだか、利用帯域がどの音源によるものか、どの特徴が個別の訂正を因果的に生んだか。並べ替えと水流音付加は同じ外乱ではない。現在の保存結果だけから気泡音源や真の気泡発生秒を同定しない。

誤り診断→入力依存→物理的解釈を、証拠の強さに応じて接続する段階まで進めた。完了した数値解析を残課題へ戻さず、物理的にどこまで言えるかと修論での説明を残す。追加の識別実験は今回は実行しない。
