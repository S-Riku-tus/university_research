# 6/11・6/18のみの双方向clean学習解析

## 結論

7/9を学習から外し、6/18のcleanだけで学習して6/11を評価したseed 42 runが完了した。既存の6/11→6/18と対にすると、cleanでは両方向ともR² .79以上、最良RMSE約75 kW/m²であり、6/11・6/18を主対象とする日付間転送は成立した。

ただしnoiseありでは方向差が大きい。両方向ともRFが最も頑健で、深層2モデルと統合はnoiseにより正bias化し、誤差相関が1へ近づいた。6/18→6/11ではSNR 0 dBの時点で深層2モデルと両統合のONB前FPRが1となった。したがって主結論は「2日なら全方式が頑健」ではなく、「cleanの日付間転送は可能だが、未知noise耐性はRFに偏り、統合の補完性はnoiseで失われる」である。

## 対象と完全性

| 方向 | run | seed | 条件 |
|---|---|---:|---|
| 6/11→6/18 | `202609/26/onb_xd-t0611-v0618_iw3-nc_s0_e150_000904` | 42 | 既存比較 |
| 6/18→6/11 | `202609/27/onb_xd-t0618-v0611_iw3-nc_s0_e150_170426` | 42 | 今回追加 |

- 22 kHz、選別なし、150 epochs、学習日内WAV非共有3-fold、`clean_only`、XAIなし。
- 両runともclean＋SNR 0、−4、−8、−12、−16、−20 dBの7/7評価条件が完了。
- 各run内の7条件は1個の`fit_id`を共有し、cleanで学習した同じモデルを全noiseへ適用。
- 7/9は学習・評価のどちらにも含まれない。

## cleanの双方向比較

RMSE、bias、ONB RMSEはkW/m²。biasは`prediction - target`。

| 方向 | 手法 | R² | RMSE | bias | ONB RMSE | ONB前FPR | ONB後Recall |
|---|---|---:|---:|---:|---:|---:|---:|
| 6/11→6/18 | RF | .876 | 95.7 | −41.8 | 153.2 | .004 | .832 |
|  | Conformer | **.924** | **75.2** | +4.3 | 90.4 | .000 | .793 |
|  | AlexNet | .846 | 106.8 | +35.4 | **70.1** | .071 | .795 |
|  | performance | .906 | 83.7 | +4.6 | 91.1 | .000 | .793 |
|  | 等重み | .907 | 82.9 | −0.7 | 97.3 | .000 | .802 |
| 6/18→6/11 | RF | **.921** | **75.5** | +30.1 | 101.7 | .045 | **.870** |
|  | Conformer | .900 | 84.8 | +37.5 | **47.8** | .000 | .844 |
|  | AlexNet | .788 | 123.3 | −44.5 | 96.9 | .000 | .812 |
|  | performance | .889 | 89.2 | −5.8 | 81.3 | .000 | .835 |
|  | 等重み | .914 | 78.6 | +7.7 | 81.8 | **.002** | .856 |

cleanの2方向平均RMSEはRF 85.6、Conformer 80.0、AlexNet 115.1、performance 86.4、等重み80.8 kW/m²。Conformerと等重みが近いが、方向ごとの最良単体はConformer→RFと入れ替わる。2日・1 seedだけで最終方式を断定しない。

等重みはcleanでbiasを相殺した。6/11→6/18ではRF −41.8、Conformer +4.3、AlexNet +35.4から等重み−0.7、逆方向では+30.1、+37.5、−44.5から+7.7となった。この相補性により、等重みは両方向でperformanceを上回った。

## performance_kfoldの重み移転

| 方向 | RF重み | Conformer重み | AlexNet重み | 内部OOF最良 | 外部最良単体 |
|---|---:|---:|---:|---|---|
| 6/11→6/18 | .256 | .357 | .387 | AlexNet | Conformer |
| 6/18→6/11 | .160 | .326 | .514 | AlexNet | RF |

内部OOF最大重みと外部最良単体は0/2方向で一致しなかった。逆方向では外部最悪のAlexNetへ.514、外部最良のRFへ.160を与えたため、performance RMSE 89.2は等重み78.6、RF75.5より悪い。

この結果は、学習日内のAlexNet性能が高いことと、別日へ最も転送できることが同義でないことを再確認する。`performance_kfold`を最終方式に採用する根拠はない。

## 7/9を外した影響

同じ6/11評価で、旧「6/18＋7/9学習」から今回の「6/18のみ学習」へ変えると、clean RMSEはRF 115.2→75.5、Conformer 135.2→84.8、performance 116.3→89.2、等重み105.2→78.6へ改善した。一方、AlexNetは87.9→123.3へ悪化した。

したがって7/9追加は全モデルを一様に悪化させたのではなく、モデル別に異なる表現・順位を生んだ。7/9を単に「悪いデータ」と断定せず、6月2日の主解析とは異なる音響ドメインとして補足結果に残す。

## 研究上の判断

### 支持されたこと

- 6/11・6/18のclean日付間転送は双方向で成立する。
- 7/9を主学習から外した6月2日限定の研究設計は実行可能。
- cleanでは単体モデル間のbias相殺により等重みが安定する。
- 未知noiseではRFが両方向とも最も頑健。
- `performance_kfold`の学習日内順位は外部日へ安定して移らない。

### 支持されなかったこと

- アンサンブルが未知noise下でRFを上回るという一般的主張。
- cleanで良いアンサンブルがnoiseでも同じ補完性を保つという仮定。
- 一方向の結果だけでnoise耐性を代表できるという仮定。

## 次の実験順序

1. 現runを逆方向seed 42の予備結果として固定する。
2. 同じ6/18 clean学習→6/11の7評価条件をseed 43・44で実行し、逆方向のseed再現性を揃える。clean_onlyは1回の学習で7 noiseを評価できるため、cleanだけを別runにして後から再学習するより現行7条件を維持する。
3. 3 seed後に、双方向でRF・等重み・performanceの全域RMSE、ONB前FPR、Recall、biasを集計する。
4. clean_onlyの結論が固定するまで、逆方向matched、ピーク選別、XAIを同時に追加しない。
5. matchedを主張に必要と判断した場合だけ、逆方向matchedを追加する。未知noise耐性が主研究質問なら、RFを基準としてclean_onlyの原因説明を優先する。

現行コードはseed 42の完了済み条件であるため、そのまま再実行しない。次に実行する場合は`random_seed`を43へ変更し、それ以外は固定する。
