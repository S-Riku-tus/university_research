「AUC」は2種類ある。連続予測ROC-AUCは閾値を動かした順位識別、二値化後AUCは固定ONB閾値で0/1にした予測による値。後者はこのrunでは感度と特異度の平均に相当する。回帰R²とONB判定を同一の優劣へまとめない。

## 統合が最良単体に届かない直接要因

- 学習側の元WAV非重複20% holdoutから `1/(1-R²)` に比例する重みを決める。保持された学習WAVは順方向17本、逆方向18本で、各holdoutは4 WAVのみ。最終重み（RF/Conformer/AlexNet）は順方向 `.170/.512/.318`、逆方向 `.149/.586/.265`。学習側の成績でConformerが優先されるが、逆方向の別日全域R²はRFが最高。
- 逆方向のONB前420秒のRMSEはRF 98.13→Ensemble 124.05 kW/m²に悪化、ONB以降660秒は68.94→50.26に改善。その差引きで全域RMSEが81.54→86.76へ悪化。Conformer単体はONB前を平均148.7 kW/m²過大予測し、253/420秒が偽陽性。統合後は偽陽性0だが、ONB前の二乗誤差は増える。
- 逆方向のONB最初のWAVではConformerが33/60秒を検知する一方、RFとAlexNetと統合は各0/60秒。統合は検知感度も一部打ち消す。
- 同一の保存済み3モデル予測を事後的に等重み平均した診断では、順方向R² `.9071`（現行 `.9038`）、逆方向 `.9124`（現行 `.8952`）。重みづけが両runの全域R²を下げたことは確認できる。ただし逆方向の連続ROC-AUCは等重み `.8925` で現行 `.8998` より低く、指標ごとの利害がある。等重み方式の採用・一般化は別日で事前固定して検証する。
- holdoutの4 WAVは選別auditとコードのGroupShuffleSplitから再現すると、逆方向では熱流束113.2、271.7、789.5、873.6 kW/m²。ONB前の低熱流束WAVは1本のみで、重みの代表性が限られる。これは重みずれと整合するが、その根本原因として確定はしない。

## 説明性の確認

- 全1080秒への帯域ゼロマスクによるR²低下が最大の帯域は、RFが両方向で2–5 kHz（順 .462、逆 .254）、Conformerが15–22 kHz（1.259、.701）、AlexNetが1–2 kHz（5.539、6.588）。モデルごとに依存の仕方が異なる。選別用2.1–2.5 kHzとモデルの利用帯域は同一概念ではない。
- ゼロマスクは入力を学習分布から外すため、R²低下の大きさだけで物理的必要性や気泡由来の音と断定できない。特にAlexNetの大幅低下はその注意が必要。
- IGは両方向ともConformerが各1/5例だけ収束。AlexNetは順2/5、逆3/5例のみ収束。代表ヒートマップの物理解釈を主張するには足りない。RFのTreeSHAPはPCA成分空間で予測再構成ができるが、その成分を物理帯域と直接呼ばない。
- 現行の説明性は単体モデルの予測を対象とし、統合の重みずれや物理的ONB発生を直接説明していない。

## 解釈と識別比較

現状の直接要因は、少数の同日内部holdoutで決めたConformer中心の重みが別日の全域RMSEに合わず、逆方向のONB前誤差増加がONB以降の改善を上回ること。帯域マスクの差は、特徴利用と日間転移の関係を調べる仮説になる。

次の比較は、修正ONB閾値・分割・seed・全テスト秒を固定し、選別あり/なし、等重み/現行重み/複数WAV分割の学習内重みを比較する。各方式でONB前後の誤差、固定閾値の見逃し/偽陽性、連続ROC-AUCを並べる。説明性はマスクの入力分布変化を確認し、必要なら対象帯域の除去後再学習と独立日で検証する。
