## 確認事実と未確定事項

白金温度には0.1→0.2 Vで82.2→80.5 ℃、1.1→1.2 Vで113.7→110.3 ℃の低下がある。CSV生成・列のずれはなく、独立した検算でも再現している。したがって「正常に計算できた」と「温度変化の物理的原因が確定した」は区別する。原因の分離は今回行っていないため、温度を単調になるよう補正しない。温度は測定電極電圧/シャント由来電流の比から求める値なので、測定電圧・電流の段階差を確認する対象になる。

1.1→1.2 Vの抵抗は採用区間平均では0.089848→0.089038 Ωと下がるが、切替直後・水温条件外を除いた段階全体の平均では0.089494→0.089533 Ωとなる。温度低下は代表区間の選択に敏感であり、実際の細線温度が必ず低下した証拠にはしない。熱流束の値が計算上整合することだけで、抵抗由来の温度の物理的妥当性まで確定しない。今回の保存階層修正では採用区間・ラベルを変更しない。

今回のシャント抵抗はNotebookの現設定0.001667 Ωで計算されている。実物の抵抗校正とWAV/ロガー同期は未確認。ONBの観察は1.2 Vを保持し、自動直線性喪失候補の1.1 Vで置き換えない。

この結果は既存の改名Notebookへ渡せる。続けて本人が音響処理を行う。現在ONBは7雑音条件、生成スクリプトはcleanのみなので、[現行の実行手順](../../docs/2026-10-07_new_experiment_processing.md)に沿って一致させる必要がある。
