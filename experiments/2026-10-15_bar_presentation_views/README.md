記録日：2026-10-15。本人がONBを実行開始した後の作図修正。本人の指定に従い、実行中のrunは探索・読込・分析せず、学習プロセスにも介入していない。確認用の数値は、以前から分析済みの10/6・seed42・200 epochsの保存CSVだけを使用した。

## 保存する図と目的

[通常作図処理](../../code/utils/plotting/regression_plots.py)の`plot_bar`から、次を保存する。指標は従来と同じR²・連続ROC-AUC・連続PR-AUC。抜粋は評価値の大小によらず固定し、元の値・SE・各棒の色を添字で引き継ぐ。必要なモデルが一つでもない構成は、その構成全体を省略する。

| 保存先 | 本数・モデル | 説明すること |
|---|---|---|
| `bar/` | 従来どおり全11方式 | 全方式の記録 |
| `bar/legacy4/` | RF・Conformer・AlexNet・`original3_performance` | 以前の3単体＋性能ベース統合に対応する構成 |
| `bar/addition4/` | 元3 MSE・元3＋HGB・元3＋ET・元3＋HGB＋ET | 元3の内部MSE重み方式を揃えて、モデル追加の効果を見る |
| `bar/integration5/` | 元3 MSE・HGB・ET・5等重み・現在の5統合 | 元3/追加単体と、等重み/現在の統合を並べる |

`original3_performance`はcatalog上で元3の`core_rule="performance"`。今回の同じ3単体の学習側OOF性能から重みを決める方式であり、学部当時の学習モデル・データの再現実行という意味ではない。`addition4`は同じ元3 MSEブロックを基準にするため、モデル追加と元3内部の重みルール変更を混ぜず説明しやすい。統合の有効性は結果を見てから判断し、この図の用意自体を改善の根拠とはしない。

## 数字と拡大版

- 棒の値を全構成共通の30 ptへ拡大。横軸モデル名・縦軸ラベルは23 ptを維持し、文字の実測幅で図を広げる。
- 5モデル統合名は`Original3`／`+ HGB + ET`の2行を維持。
- 通常版は0を含む縦軸を維持し、負のR²や誤差棒があればその範囲まで表示する。
- 各構成の拡大版を同じ場所に`*_zoom.png`として追加。全平均値と誤差棒の範囲から上下限を決め、`Zoomed y-axis`・軸目盛・省略記号を表示する。値は再正規化しない。
- 拡大版の数字は棒の上に横書きで「値」「± SE」の2行。表示倍率は各構成に合わせるため、異なる拡大図の棒の高さだけを直接比較せず軸目盛も読む。
- 全値未定義、または広い範囲に分散して拡大の効果が小さい場合は拡大版を作らない。通常の保存名は変更しない。

保存SEが0のときはこれまでの表記を引き継ぐ。外側1分割のSE=0を不確かさゼロの証拠にはしない。指標の再計算・定義変更は行っていない。

## 今回実行中のrunへの適用

既に起動しているPythonは作図クラスをimport済みのため、ファイル変更が自動反映されるとは限らない。今回の学習を止めたりやり直したりせず、終了後に[再描画専用入口](../../code/replot_regression_bars.py)を使えるようにした。

```powershell
python code/replot_regression_bars.py --run-dir "完了したrunのフォルダ"
```

指定できるのは、manifest/CSVがある条件フォルダ、その親の周波数フォルダ、またはさらに親の当該runフォルダ。対象は指定フォルダ内の既存結果だけで、別runを自動追加しない。全対象の`completed.json`とrun hash、広い範囲を指定した場合は設定済み雑音条件の存在を確認してから描画する。完了印はこの処理の入力整合性確認であり、学習や研究上の結果分析を代行しない。

既定の出力は`指定フォルダ/bar_redraw/時刻/`配下で、その中に`bar/`・抜粋サブフォルダと`redraw_manifest.json`を保存する。元の図・CSV・モデル・manifestを上書きせず、保存済みの平均/SEを使う。再学習もモデル推論も行わない。今回はこの入口を実行中runへ適用していない。
