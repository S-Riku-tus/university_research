# 6/18 clean学習→6/11評価・5周波数×3 seed解析

## 結論

6/18のcleanだけで学習し、6/11のclean＋6 noiseを評価する逆方向について、seed 42/43/44、3/5/10/15/22 kHzの計3 run・105条件が完了した。7/9は含まれない。

22 kHzではseed 42の結論が再現し、noiseあり平均RMSEはRF 128.8±5.9、等重み216.3±6.8、performance 246.5±20.6 kW/m²だった。一方、3–5 kHzでは劣化が大幅に小さく、全noise平均は5 kHz RF 90.5±1.5、3 kHz performance 91.1±3.1、3 kHz AlexNet 91.1±6.7、3 kHz等重み92.0±3.0 kW/m²だった。

3 kHz等重みはRFを21 seed×noise条件中20条件で上回り、moderate noiseでは最良単体も上回る場合が多い。しかし最良単体に勝ったのは11/21、2%以内は12/21で、暫定基準14/21に未達だった。−16・−20 dBではAlexNet単体が統合より良い。したがって「低周波域でアンサンブルがRFのnoise劣化を抑える」は支持されるが、「アンサンブルが常に最良単体を上回る」は支持されない。

## SNR別の境界

各SNRで全周波数・方式からRMSE最小となった主な組合せは次の通り。

| SNR | 最小RMSE | 次に近い候補 | 解釈 |
|---|---:|---:|---|
| clean | 10 kHz等重み 73.4 | 10 kHz RF 73.8 | 差は小さく事後選択 |
| 0 dB | 10 kHz RF 73.8 | 3 kHz等重み 73.9 | ほぼ同等 |
| −4 dB | 5 kHz RF / 3 kHz等重み 74.0 | 10 kHz RF 74.3 | 低～中帯域が安定 |
| −8 dB | 5 kHz RF 74.1 | 3 kHz performance 77.4 | 5 kHz RFが優位 |
| −12 dB | 5 kHz RF 76.4 | 3 kHz Conformer 85.1 | 5 kHz RFが優位 |
| −16 dB | 5 kHz RF 87.9 | 3 kHz AlexNet 98.2 | 5 kHz RFが優位 |
| −20 dB | 3 kHz AlexNet 112.5 | 3 kHz performance 132.6 | 極強noiseでは3 kHz深層単体 |

固定方式として全noiseを平均すると5 kHz RFが最も安定する。一方、極強noiseだけでは3 kHz AlexNetが最良であり、方式順位はnoise強度で変わる。評価SNRを見て方式を切り替えるのは事後選択なので、実運用方式としては扱わない。

## 3 kHzアンサンブルの成立範囲

3 kHzの21 seed×noise条件に対して、等重みはRFを20/21、performanceは17/21で上回った。RF比の平均RMSE差は等重み−8.79、performance−9.30 kW/m²である。

一方、各条件の最良単体との比較は次の通り。

| 方式 | 最良単体に勝利 | 最良単体2%以内 | 平均ΔRMSE |
|---|---:|---:|---:|
| performance | 8/21 | 11/21 | +4.17 kW/m² |
| 等重み | 11/21 | 12/21 | +4.68 kW/m² |

等重みはSNR 0・−4 dBで3/3 seed、−8 dBで2/3 seedにおいて最良単体を上回った。しかし−16・−20 dBでは0/3で、強noiseではAlexNet単体に負けた。よって、アンサンブル効果はmoderate noiseまでに限定される。

## 周波数上限の解釈

3 kHzは、これまで注目してきた2.1–2.5 kHz帯域を保持しながら、それより上の成分を除く。3–5 kHzでdeep modelのnoise劣化が小さく、15–22 kHzで急激に悪化したことは、低周波側に転送可能な情報があり、高周波側が付加noiseへの感度またはshortcutを増やしたという仮説と整合する。

ただし`maxfreq`を変えると、単に高周波を切るだけでなく、0～上限周波数を224画素へresizeする際の1画素当たり周波数幅も変わる。したがって現結果だけで「3 kHz以上の成分が有害」と因果断定しない。帯域マスク、同一周波数解像度、説明性で識別する必要がある。

## performance_kfoldの重み移転

逆方向の15 seed×周波数cellで、内部OOF最良単体と外部clean最良単体の一致は0/15、平均順位相関は−.700だった。

周波数平均では内部OOF R²がRF .814～.821に対しConformer .916～.938で、RF重みは.152～.197に抑えられた。一方、外部clean R²は全5周波数でRFが単体最良だった。学習日内順位が別日では逆転しているため、`performance_kfold`を主方式に採用しない。

## 研究上の判断

### 支持できる

- 6/18→6/11において、3–5 kHzは15–22 kHzより未知noise下で安定する。
- 5 kHz RFは全noise平均で最も高精度かつseed安定性が高い。
- 3 kHz等重み・performanceはRFよりnoise劣化を抑える。
- 3 kHzの統合効果はmoderate noiseで強く、強noiseではAlexNet単体が優位になる。
- 22 kHzではRFが未知noiseに最も頑健で、deep・統合の全陽性化が再現する。
- performance重みの学習日内順位は外部日へ移らない。

### まだ支持できない

- 3–5 kHzの優位が6/11→6/18でも再現すること。
- 2.1–2.5 kHz帯域そのものが改善の原因であること。
- アンサンブルが全noise・全単体モデルより常に良いこと。
- 5 kHz RFが未知の日付一般に最良であること。

## 次に行うこと

1. 逆方向は3 seedが揃ったため、同じ条件を追加実行しない。
2. 周波数効果の日付方向依存を識別するため、6/11 clean学習→6/18評価で3 kHz・5 kHzをまずseed 42で実行する。22 kHzは既存3 seedを使い、再実行しない。
3. 3/5 kHzの傾向が順方向でも再現した場合だけseed 43・44を追加し、双方向×3 seedを完成させる。
4. 周波数上限を固定後、3 kHzと22 kHzの代表条件でgroup occlusionを行い、2.1–2.5 kHz保持・除去時の予測変化を比較する。IGは補助とする。
5. `performance_kfold`は主方式から外し、RFを頑健単体基準、等重みを単純統合基準として扱う。

現行コードはseed 44・逆方向・5周波数の完了済み条件であり、そのまま再実行すると重複する。
