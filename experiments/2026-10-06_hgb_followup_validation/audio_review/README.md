# 原録音の確認用抜粋

2026-10-06最新：追加の人手確認から新しい事実が得られない前提。既存の診断資料として保持し、本人の確認・記入を要求しない。[現在の扱い](../human_review_instructions.md)。以下は作成時の説明である。

録音内の対象1秒と前後最大1秒を、増幅・正規化・雑音追加せずに抜き出した。対応表は親フォルダのhuman_review_sheet.csv。evaluation_noiseは解析条件で、このWAVへ人工雑音を加えたという意味ではない。モデル入力のhighpass/STFT加工前の音声である。音だけから気泡発生を確定せず、録音異常の有無と同期観測の所在を記入する。
