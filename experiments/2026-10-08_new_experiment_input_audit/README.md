- 次の識別比較：旧日の対応段階との比較、固定済みモデルの別日適用、予測の成功/失敗と特徴変化の対応。物理音源の同定はこの入力確認とは別工程。

図の周波数は224へのresize後の近似対応、powerは未校正。線径等を条件対応する前に、音響ピークを気泡固有周波数と呼ばない。
