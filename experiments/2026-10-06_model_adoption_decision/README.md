# 既存3モデルに対する追加候補と統合方式の採用判断

**同日後継**：本人が元RF/Conformer/AlexNetを固定して追加する意図を明確化したため、[元3固定の4・5モデル追加比較](../2026-10-06_fixed_three_additions/README.md)へ主方針を更新した。9候補を実際に学習し、元3＋HGB＋ExtraTrees5を主候補、元3＋ExtraTrees4/HGB4を対照とする。以下のRF置換採用は当時の判断記録として保持し、現在の主方針とは扱わない。

2026-10-06。本人の最新指示は、追加の原録音確認・実験メモ・同期映像から新しい事実が得られない前提で進め、モデルと統合方式の採用判断もAI側に任せること。追加の人手確認を次工程に置かない。物理的な音源や瞬間的な気泡の有無は未確認の限界として固定し、既存データの予測・誤り・入力依存から判断する。

**現時点の主採用は、周波数34特徴HGB＋Conformer＋AlexNetを、clean学習OOFのMSE最小化による非負重みで統合する方式。** 既存RF＋Conformer＋AlexNetを基準対照として保持する。Ridgeは最有力の統合対照として残し、全雑音条件で最良の方式が確定したとは主張しない。[採用判断JSON](../../configs/experiments/2026-10-06_model_adoption_decision.json)。

## 1. 「何を追加したか」を三つに分ける

| 比較の軸 | 実際に検証したもの | 判定する問い |
|---|---|---|
| 学習器 | RBF-SVR、HistGradientBoosting回帰（HGB） | 既存3とは異なる学習方式が有用な予測を加えるか |
| 入力表現 | 基礎10、周波数34、時間分布46特徴 | どの情報を残すと誤りが変わるか |
| 統合 | 等平均、performance、MSE最適化、多様性項、Ridge、雑音OOF方式、部分集合 | 候補の利得を取り込めるか、候補の失敗を抑えられるか |

既存RFの実装はXGBRFで、PCA100を通した画像特徴を使う。HGBは同じスペクトログラムから計算した34特徴を使う。したがって最初の既存RF対HGBの差には、入力と学習器の両方が関わる。「HGBという名前のモデルがRFより普遍的に優れる」という比較ではない。

基礎10は帯域power、比率、重心、entropy、時間powerのCV。周波数34は125 Hz幅24帯域の相対log-powerを追加する。時間46は6帯域の時間分布の分位点・CV・peak比などを追加するが、時間順序を保持しない。最初は2学習器×3入力×3選択方針の18候補方針を試し、周波数HGBを固定してseed43/44で既存3も作り直す追検証まで進めた。

根拠：[最初の予備比較](../2026-10-06_chunk_complementary_model_pilots/README.md)、[追加seedと説明・統合比較](../2026-10-06_hgb_followup_validation/README.md)。

## 2. 追加モデルの良い点・悪い点

以下はseed42の開発比較、学習側RMSEで選んだ候補の同じ外側540。各行のFN母数315、FP母数225、誤差単位kW/m²。q100優先・FP優先の選択方針も実行したが、この表には同じRMSE方針だけを載せる。

| 学習器と入力 | clean RMSE | clean FN / FP | −20 RMSE | −20 FN / FP | 現在の扱い |
|---|---:|---|---:|---|---|
| SVR・基礎10 | 55.43 | 28 / 2 | 360.11 | 65 / 0 | 現設定は採用しない |
| SVR・周波数34 | 34.85 | 22 / 1 | 203.23 | 0 / 224 | clean補完の余地はあるが主候補から外す |
| SVR・時間46 | 40.98 | 29 / 2 | 220.85 | 31 / 225 | 現設定は採用しない |
| HGB・基礎10 | 37.73 | 21 / 0 | 98.32 | 49 / 1 | 情報を増やす効果を見る対照 |
| HGB・周波数34 | 33.25 | 21 / 0 | 74.19 | 49 / 0 | 主採用する追加モデル |
| HGB・時間46 | 30.94 | 25 / 2 | 75.11 | 41 / 4 | 第2候補として保持 |

根拠：[pilot_model_inventory.csv](pilot_model_inventory.csv)。予備比較の数値を新seedの値で置き換えず、段階を分けて読む。

**周波数HGBを選ぶ理由**：cleanの内部OOFでは既存3共通FN52の22例を訂正し、追加seedの外側でも共通FN21/19の7/6例を訂正した。HGBを統合に加えた回帰・見逃しの改善が新しい2分割で残った。重要度が違うだけでなく、誤りの訂正という結果が伴っている。

**SVRを主候補から外す理由**：周波数34のcleanは良いが、−20ではONB前225例中224例を陽性にし、FN0になった。逆方向の出力や高いRecallだけでは有用な補完にならない。この結果は今回のRBF-SVR・入力・設定に限定し、SVR一般を否定しない。

**時間HGBを完全に捨てない理由**：seed42のclean RMSEは周波数HGBより良く、−20 FNも少ない。一方、clean/雑音のFPと内部雑音OOFの不安定さが大きい。内部−20のFPは時間46が105/675、周波数34が7/675だった。HGBをleaf15で固定すると時間46の外側−20 FPは92/225、調整後のleaf31では4/225と設定感度がある。まだ新しい2 seedの対応比較がなく、現段階で主候補へ昇格する根拠は足りない。

**ExtraTreesの状態**：以前のWAVを分ける内部fold・基礎10特徴では試したが、現在のshuffled chunk fold・同じ周波数34特徴での検証は未実施。以前の結果から現在の条件での不採用を決めず、候補として残す。

## 3. 元の3モデルは、追加後にどういう役割になるか

単体のclean RMSEはseed43/44で、RF70.97/69.60、Conformer33.12/35.50、AlexNet58.28/64.25、周波数HGB28.33/28.88。ただし単体誤差の順位だけでモデルを取り除かない。

Conformer＋HGBの2モデルはclean RMSE25.81/27.02と良いが、seed43 −20ではFP12になった。AlexNetを含む3モデルMSEでは両seedの全7条件でFP0だった。**AlexNetは単体の誤差が大きくても、今回の統合では候補の高い出力を抑える役割がある。** その効果と回帰性能は条件によるので、普遍的な役割とはしない。

4モデルMSEのRF重みは両seedとも0。Conformer＋AlexNet＋HGBの3モデルMSEは、4モデル版と全7560個の外側予測を照合し、最大差約0.00024 kW/m²、二値判定は全件一致した。[verification.json](verification.json)。そこで実際の推論ではRFを外す構成を主採用する。

これはRFを今後一切使わない判断ではない。既存3の比較基準として保持する。またRidge統合ではRFの係数が両seedで負になっており、RFを使った誤差補正も行われている。MSEで重み0という事実を、別の統合でもRFが無価値という結論へ広げない。

## 4. 主採用する統合方式と、その理由

| 方式 | seed43 clean RMSE / FN / FP | seed44 clean RMSE / FN / FP | −20 RMSE（43 / 44） | 判断 |
|---|---|---|---|---|
| 既存3 clean-MSE | 35.74 / 32 / 0 | 33.89 / 28 / 0 | 81.41 / 81.41 | 公平な基準対照 |
| Conformer＋AlexNet＋HGB clean-MSE | **27.36 / 25 / 0** | **26.51 / 21 / 0** | 90.02 / 73.83 | **主採用** |
| HGB追加 clean Ridge | 25.99 / 22 / 0 | 25.85 / 16 / 1 | 86.80 / 73.07 | 最有力の統合対照 |
| HGB追加 多様性項 | 28.60 / 25 / 0 | 26.59 / 21 / 0 | 91.10 / 73.32 | 今回の固定項は主採用しない |
| HGB追加 雑音OOF-MSE | 28.79 / 25 / 0 | 31.08 / 25 / 0 | 83.99 / 77.00 | 雑音へ露出する別条件の対照 |
| HGB追加 雑音OOF-Ridge | 30.54 / 28 / 0 | 32.01 / 30 / 0 | 78.02 / 76.89 | 雑音回帰と見逃しの交換を見る対照 |

MSE主方式の重みはseed43でConformer11.66%・AlexNet25.51%・HGB62.83%、seed44で24.00%・11.97%・64.04%。これらを平均して固定値として採用するのではなく、同じ規則で各runのclean OOFから重みを求める。

採用は次の理由を組み合わせた研究上の判断である。数値的なFP許容上限や一意な総合得点を新しく作ったわけではない。

1. 元の3にも同じMSEを使った対照に対し、clean RMSE・MAE・FNの改善が両seedで再現した。両seedで26/36 WAVが改善し、少数例だけの恩恵ではない。
2. q100が動かないseed44でも他指標が改善した。q100不変を不採用理由にはしない。
3. 主方式は両seedの全7条件で観測FP0。単体HGBのseed43 −20 FP88を抑え、Conformer＋HGBだけのFP12も避けた。
4. 基礎モデルと重みをすべてcleanで決めるため、本人が主に検証したいclean_onlyの問いに対応する。
5. RFなしの構成で既存4モデルMSEの結果をほぼそのまま保持できる。今回見つかったRF/PCAの数値環境依存も、この主方式の推論経路から外せる。

**Ridgeを主方式にしない理由も、良い点と対にして判断する。** Ridgeは新2 seedでclean RMSEをMSEより平均約1.02 kW/m²下げ、FNも3/5例減らした。したがって悪い方式ではなく、強い競合である。一方、q100はMSEと同じ、seed44ではFP1が追加され、seed42の開発比較ではFN24→26、FP0→1という別の代償もあった。現時点では繰り返し確認された回帰・判定改善とFP抑制を主結果にし、Ridgeの追加利得と代償を対照として示す。

RidgeのFP1は6/18の225.70 kW/m²、chunk33、予測272.37、ONB閾値271.68。閾値超過は約0.70だが、正解段階と閾値の差は約45.97である。閾値をわずかに超えたことを理由に正解の不確かさや実際の気泡を推測して、誤報から除かない。

**等平均と今回の多様性項**：4等平均のclean RMSE33.70/34.09、FN38/39は主方式より悪い。モデルを増やすだけでは不十分。多様性項も今回の固定値ではclean FN/q100を追加改善せず、RMSEを上げた。輪講のsociety entropyを直接再現した実験ではないため、今回の結果から多様性の考え方全体を否定しない。

## 5. 主採用しても残る不足

主方式のclean改善は確認できたが、雑音回帰の優位は安定していない。−20 RMSEは既存3に対しseed43で81.41→90.02と悪化、seed44で81.41→73.83と改善した。低熱流束60未満のclean RMSEも両seedで悪化した。全域の成功と、領域・雑音条件の失敗を両方残す。

HGB単体は、学習chunkを固定してモデル乱数だけ変えた4比較では予測差0だった。一方、学習chunkを変えると強雑音の誤報が大きく変わった。各内部fitには全36 WAV・全熱流束段階がある。現在の課題は段階支持を戻すことから、**どの学習例で得た予測関数が、雑音で変わる入力分布にも安定するか**へ移っている。

周波数entropyがclean学習範囲外となる例は、誤報と正しい陰性の両方に多い。entropyだけでHGB使用/不使用を切り替える規則は、この事実からは導けない。真のSNRや熱流束を知って重みを切り替えることも、実際の推論には使えない。

物理的な音源は追加情報がなく未確認のままとする。説明性から述べるのは「モデルがどの帯域や要約に依存するか」「加工でどの予測が変わるか」「どの誤りを補完するか」であり、「その帯域で気泡が出た」とはしない。この制約はモデル比較と採用を止める理由ではない。

## 6. 他に検討する余地と優先順位

### 第1優先：同じ周波数34入力でHGBの正則化を限定比較

モデル名を増やす前に、既に有用だったHGBの分割感度を減らせるかを調べる。leaf数、最小leaf標本数、L2のうち少数を変える。まず基準31/20/1に対しminleafを40にする対照、L2を10にする対照など、一要因ずつの比較を置く。木の細かい適合を制限する設計だが、強雑音の誤報低下を保証しない。[使用環境1.6のHGB公式仕様](https://scikit-learn.org/1.6/modules/generated/sklearn.ensemble.HistGradientBoostingRegressor.html)。

新しい候補は保存済みseed43/44の同じfoldへ合わせれば、既存3を毎回再学習せずに公平な追加比較ができる。候補パラメータの選択は各fit内の検証で行い、外側の良かったseedだけを選ばない。cleanだけで候補を決める主対照と、雑音OOFも使って候補を決める条件を分ける。

### 第2優先：同じ34特徴のExtraTreesと直接Ridge/PLS

**ExtraTrees**は複数のランダム化した木を平均する学習器で、逐次残差を補正するHGBとの対照になる。[公式仕様](https://scikit-learn.org/1.6/modules/generated/sklearn.ensemble.ExtraTreesRegressor.html)。今回の元RFはPCA画像入力なので、ExtraTreesにも同じ34特徴を与えることに意味がある。入力を固定したうえで学習方式を変え、clean利得と強雑音の分割感度がどう変わるかを判別する。

**直接Ridge/PLS**は、34特徴から熱流束を予測する基礎モデル候補である。今回の「4モデルの出力を受け取るRidge統合」とは別物。小さな特徴変化への反応を、木の分岐とは異なる線形関係で比較できる。RidgeはL2正則化、PLSは成分数を制限する対照とし、scalerやPLSを各fitだけで学習する。[Ridge公式](https://scikit-learn.org/1.6/modules/generated/sklearn.linear_model.Ridge.html)、[PLS公式](https://scikit-learn.org/1.6/modules/generated/sklearn.cross_decomposition.PLSRegression.html)。予測が安定してもcleanで有用な訂正が減る可能性があり、有効性は未検証である。

同じfold内のfitだけから複数HGBをbootstrap学習して平均する方法も候補にできる。ただし、既存のseed43/44の最終モデルをそのまま平均して片方のテストで評価しない。他seedの学習へそのテストchunkが入っている可能性があるため、OOFと外側のそれぞれで評価chunkを使わない平均を作る。

### 第3優先：時間46の再現確認、時間順序を使うモデル、ONBの直接分類

時間46 HGBはcleanの別候補として、同じ追加2 seedで確認する価値がある。さらにイベントの順番を使う小型時系列モデルは、時間順序を捨てた要約とは別の比較になる。ただし現在のConformer/AlexNetも時間構造を入力に持つため、新しい構造に変えるだけで共通失敗が解消するとは言えない。

ONB前後の判定を直接学習する分類器も検討余地がある。熱流束RMSE最小化と二値判定の目的は一致しないため、q100やFN/FPを主に改善したい段階の別比較になる。現行録音段階のラベルから実施でき、追加映像を前提にしない。一方、分類器を足すだけでは熱流束回帰の改善にならず、出力確率100%と有限標本のq100を同一視しない。

局所的な重みや入力依存のgate、別の多様性指標は、以上の単体比較で既存主方式の不足が具体化してから進める。真のSNRを入力せずに使える特徴を選び、メタモデル自体の過適合も確認する。今の残差相関項に利得がなかったので、違う多様性を自動的に主採用する段階にはない。
