# trush_box の扱い

このフォルダは、過去の試行コードや一時的に退避したコードを置いている場所です。名前はそのまま残していますが、意味としては `legacy` や `archive` に近い場所です。

## 使い方

- すぐに削除しない。
- 必要な処理を見つけたら、中心スクリプトや `code/utils/` に取り込む。
- 使った場合は、どの処理を参考にしたかを `docs/code_map.md` や実験サマリーに書く。

## 注意

- ここにあるコードは、古いパスや古い条件を前提にしている可能性が高い。
- 実行前に、入力パス、出力パス、SNR、chunk、maxfreqを必ず確認する。
