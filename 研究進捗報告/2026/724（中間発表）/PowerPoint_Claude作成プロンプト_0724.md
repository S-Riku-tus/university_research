# PowerPoint内Claude用プロンプト

以下をPowerPoint内のClaude拡張機能へ、そのまま入力してください。

---

```text
現在PowerPointで開いている過去の研究進捗報告資料をテンプレートとして使用し、以下の内容で新しい中間発表スライドを作成してください。

【最重要の前提】

現在開いている資料は、内容ではなくデザインだけを参照するための資料です。
過去資料に書かれている研究結果、数値、文章、結論は今回の発表内容として使用しないでください。
以下に指定する新しい内容へ置き換えてください。

【絶対に変更しないデザイン要素】

- スライド左端にある縦方向の装飾、見出し、帯、ライン
- スライド上部にある見出し、横線、罫線、アクセント
- 大学名、研究室名、ロゴ、ページ番号、フッター
- スライドマスター、背景、テーマカラー
- 現在の資料で使用されているフォントファミリー
- 既存資料全体の視覚的な統一感

これらは削除、移動、変形、色変更、置換をしないでください。
ロゴを新しく描き直したり、別のロゴへ置き換えたりしないでください。
フォントも別のフォントへ変更しないでください。

【調整してよい要素】

- 新しく追加する本文の文字サイズ
- 本文、表、図、矢印などの配置
- 箇条書きの行数と改行位置
- 情報量に応じた余白
- 既存テーマカラーの範囲内での強調色

文字サイズや配置は、元資料の雰囲気を保ちながら、読みやすく、余白のある研究発表資料になるよう調整してください。
文章が枠内に収まらない場合は、無理にフォントを小さくせず、文章を短くするかレイアウトを変更してください。
本文は会場で読める大きさを維持してください。

【全体の作成方針】

- 日本語で作成する
- 全12枚程度で構成する
- 1枚につき中心メッセージは1つにする
- 細かな性能数値や大量の表は載せない
- 今回の中心は「年間計画に対する現在地」と「残っている研究課題」とする
- モデルの優劣を断定する発表にはしない
- 実装が完了したことと、研究上の検証・解釈が完了したことを区別する
- 過去資料の内容を要約したり再利用したりせず、以下の文章だけを内容の根拠とする
- 装飾的なイラストや外部のストック画像は追加しない
- 必要な図は、既存テーマに合うシンプルな矢印、工程図、表、タイムラインで作成する
- カードを大量に並べるデザインにはしない
- 文章を詰め込みすぎず、発表者が口頭で補足できる構成にする

【研究内容の正確な表記】

- 研究の主軸は「音響スペクトログラムからの熱流束回帰と、予測熱流束を用いた沸騰開始点近傍の検知」
- 使用モデルは「RandomForest系モデル」「CNN+Transformer v2 GAP」「AlexNet」
- CNN+Transformer v2 GAPを「Conformer」と表記しない
- RFは実際にはXGBRFRegressorを使用しているが、スライド上では必要に応じて「RF系モデル」と簡潔に表記してよい
- 「説明性指標」という言葉だけに統一せず、「説明手法」と「説明の信頼性を評価する指標」を区別する
- ONB近傍専用の現行指標は、ONBしきい値の±10%に入る標本のRMSE/MAE
- Recall、F1、False Negativeは、ONB近傍だけでなく全標本をしきい値で二値化した検知指標
- 検知遅れ、リードタイム、100%分類可能な熱流束下限は、現時点で確立済みの主指標として扱わない

以下のスライド構成で作成してください。

サブタイトル：

柴崎陸

今回の発表内容

5. 沸騰開始点近傍の評価方法

数字を大きめにし、5項目を縦に並べてください。

タイトル：
修士研究で取り組むこと

音響スペクトログラムから熱流束を回帰予測し、
予測熱流束を用いて沸騰開始点近傍を検知する。

実験音声
→ スペクトログラム
→ RF系 / CNN+Transformer / AlexNet
→ 予測熱流束
→ ONBしきい値による検知

工程図の下または右側に、以下を簡潔に配置してください。

- 回帰性能
- ノイズ・条件変化への安定性
- 時間・周波数方向の判断根拠
- ONB近傍の見逃し

このスライドでは、研究目的を「高精度なモデル探し」だけに見せないでください。

年間計画と現在の位置

7月時点で予定していた状態

- ④ ONB向けデータ設計・入力表現を検討

実際の状態
- ①は完了
- ②は3モデル同時評価まで前倒し
- ③も説明出力まで前倒し
- ④のデータ設計・入力表現は遅れ

色分けする場合は、既存資料の色を優先してください。
必要であれば、完了、進行中、今後の3状態だけを区別してください。

年間計画に対する現在の到達度

以下を4行の表で示してください。

残っていること：
アンサンブルの有効性と最終方式の判断
現在の判定：
実装基盤は完了

項目：
③ 各モデルへの説明性付与
完了したこと：
手法決定、実装、代表条件での出力
残っていること：

現在の判定：
進行中

完了したこと：
ONB近傍誤差としきい値検知指標を導入

データ設計、入力表現、検知遅れ、一般化検証
現在の判定：
着手段階

表が窮屈になる場合は、「完了したこと」と「残っていること」を短くしてください。
進捗率を数値で大きく示す必要はありません。

スライド6　未完了部分と理由
────────────────────────

タイトル：
現在残っている課題と理由

左側：
現在残っている課題

1. 説明性出力の確認と解釈
- 手法間・条件間で結果が整合するか
- 物理的に妥当な周波数・時間領域か

2. ONBに特化した研究設計
- ONB近傍の正式な定義
- データの刻み幅・入力表現
- 見逃しと検知遅れの評価

3. 評価方法の妥当性
- chunk単位分割と未知条件への一般化
- ノイズ条件の評価方法

右側：
未完了となった理由

- CNN+TransformerとAlexNetの精度回復を優先した
- 中間発表に向け、説明性手法の実装を前倒しした
- モデル実装後に評価設計上の確認事項が見つかった

左右を独立した大きな領域として配置してください。
カードを重ねるようなデザインにはしないでください。

────────────────────────
スライド7　今後の実施順序
────────────────────────

タイトル：
今後の実施順序

以下を上から下、または左から右の5段階フローとして示してください。

1. 説明性出力を確認
代表標本、モデル間、ノイズ条件間を比較

2. ONB近傍評価を正式に定義
近傍幅、Recall、False Negative、検知遅れ、評価単位

3. ONB向けデータ・入力表現を設計
ONB前後の刻み、時間分解能、周波数表現

4. 評価分割と一般化条件を見直す
元WAV単位、実験日単位、未知ノイズ条件

5. 単体モデル・アンサンブル・説明性を再検証
最終モデルと主張できる範囲を確定

下部に小さく時期の目安を示してください。

7月末-8月：
説明性出力の確認、ONB評価定義

8-9月：
データ設計、入力表現、評価分割

9-12月：
各モデル、一般化性能、早期検知の検証

1月以降：
最終図表、修論執筆

タイトル：
説明性評価の現在地

左側：
完了したこと

- RFのTreeSHAP出力
- CNN+Transformer / AlexNetのIG出力
- AlexNetのGrad-CAM出力
- 全モデルの周波数帯・時間帯マスク比較

スライド11　ONB近傍を評価する理由と現在の指標
────────────────────────

タイトル：
沸騰開始点近傍の評価

上部の中心メッセージ：

全体の回帰誤差が小さくても、
ONBしきい値付近では小さな予測誤差が見逃しにつながる。

中央に、熱流束軸とONBしきい値を示す概念図を作成してください。

低熱流束
→ ONB近傍
→ 高熱流束

ONBしきい値の左右に「q_ONB ± 10%」の帯を表示してください。

下部に以下の指標を簡潔な表で示してください。

ONB近傍RMSE / MAE：
真値がONBしきい値の±10%に入る標本の予測誤差

Recall / False Negative：
ONB以上の標本を見逃していないか

F1：
見逃しと誤検知のバランス

マスク後の指標変化：
時間・周波数領域とONB検知性能の関係

右下または下部に、今後必要なことを短く示してください。

- ±10%という近傍幅の妥当性確認
- 検知遅れ・リードタイムの定義
- ONB前後を細かく測るデータ設計
- 元WAV・実験日単位の一般化評価

タイトル：
まとめ

年間計画に対する現在地

- ① RF単体の回帰からONB評価までの基盤は確立
- ② 3モデルの安定化と統合評価の実装は完了
- ③ 説明手法は選定・実装済み、結果解釈は進行中

次に行うこと

1. 説明性出力の目視・信頼性・物理妥当性確認
2. ONB近傍と検知遅れの正式な定義

4. 同一条件での最終比較と一般化検証

最下部に、今回の発表全体の結論として次の文章を配置してください。

モデル実装は計画より前倒しで進んだ一方、
今後は説明結果の検証とONB専用の研究設計を優先する。

【最終確認】

作成後、次を確認して必要なら修正してください。

1. 左端の装飾、上部の見出し・罫線、ロゴ、フッターを変更していないか
2. 元資料と異なるフォントを使っていないか
3. 過去資料の数値や文章を誤って残していないか
4. 「Conformer」と誤表記していないか
5. 文字が小さすぎたり、枠からはみ出したりしていないか
6. 表や図がロゴ、ページ番号、見出しと重なっていないか
7. 細かな精度値の発表になっていないか
8. 「実装完了」と「研究上の検証完了」を区別できているか
9. 1枚につき中心メッセージが1つになっているか
10. 全スライドが現在開いている資料のデザインと統一されているか

可能であれば、各スライドの発表者ノートに、そのスライドの中心メッセージを2～4文で追加してください。ただし、スライド本文へ説明文を詰め込みすぎないでください。
```
