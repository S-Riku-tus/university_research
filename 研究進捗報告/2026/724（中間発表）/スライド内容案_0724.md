## 1. 進捗を判断するときの基本方針

「コードが動く」と「研究として結論を出せる」を分けて説明する。

| 段階 | 意味 |
| --- | --- |
| 実装完了 | 学習、予測、評価、保存まで一通り実行できる |
| 検証完了 | 出力を確認し、比較条件や評価方法に問題がない |
| 研究上の完了 | 結果を解釈し、研究目的に対する結論を説明できる |

この区別を置かない場合、③について「説明性手法を実装したので完了」と言った直後に、「結果はまだ見ていない」と説明する矛盾が生じる。

発表では、工程の目安として以下のように整理する。

| 年間計画の項目 | 現在の扱い | 発表用の進捗目安 |
| --- | --- | ---: |
| ① RF単体の確立 | 完了扱い | ほぼ100% |
| ② 3モデルアンサンブルの確立 | 実装基盤は完了、効果の判断は継続 | 80-90% |
| ③ 各モデルへの説明性付与 | 手法決定・実装・出力まで完了、解釈を確認中 | 60-70% |
| ④ 沸騰開始点へのアプローチ | 評価指標の基盤のみ着手 | 10-20% |
| ⑤ 修論執筆・まとめ | 計画上、今後着手 | 未着手 |

割合は厳密な工数ではなく、発表で残作業の大きさを伝えるための目安である。

### スライド8 各モデルで採用した説明性手法

#### スライドに置く表

| モデル | 主な説明手法 | 何を見るか | 注意点 |
| --- | --- | --- | --- |
| RF | PCA空間のTreeSHAP | RF内部で各PCA特徴が予測へ与える寄与 | PCA特徴を周波数帯へ直接読み替えない |
| CNN+Transformer v2 GAP | Integrated Gradients | 入力スペクトログラム各位置の回帰出力への寄与 | 説明の安定性を別途確認する |
| AlexNet | Integrated Gradients、Grad-CAM | 入力寄与とCNNが注目した大まかな領域 | Grad-CAMは粗い補助表示 |
| 全モデル共通 | 周波数帯・時間帯マスク | 特定領域を除いたときの性能低下 | 物理軸でのモデル横断比較に使用 |

#### 話す内容

説明手法は無理に1種類へ統一せず、各モデルの構造に合わせて選んだ。RFではTreeSHAPを使うが、入力がPCA特徴なので、TreeSHAPだけから特定の周波数帯が重要とは言えない。そのため、全モデルに同じ周波数帯・時間帯マスクを適用し、ある領域を消したときに回帰性能やONB近傍性能がどれだけ悪化するかを共通の比較軸とする。

現在使用しているモデルは、厳密なConformerではなく「CNN+Transformer v2 GAP」と表記する。

### スライド11 現在導入しているONB評価指標

#### スライドに置く表

| 指標 | 現在の定義 | 目的 |
| --- | --- | --- |
| ONB近傍RMSE / MAE | 真の熱流束が実験別ONBしきい値の±10%に入る標本だけで誤差を計算 | しきい値近傍で回帰値がどれだけずれるか |
| Recall | 全標本をONBしきい値で二値化し、実際にONB以上の標本を検知できた割合 | 沸騰側の見逃しを確認 |
| False Negative | 真値はONB以上だが予測値がONB未満の件数 | 見逃し数を直接確認 |
| F1 | PrecisionとRecallの調和平均 | 見逃しと誤検知のバランス |
| マスク後の指標変化 | 周波数帯・時間帯を除いた後のONB RMSE、Recall、FNの変化 | 説明性とONB検知を接続 |

#### 話す内容

現在、ONB近傍専用として実装されているのは、真値がONBしきい値の±10%に入る標本だけで計算するRMSEとMAEである。RecallとF1はONB近傍だけではなく、全標本をしきい値で二値化した検知指標である。特にRecallとFalse Negativeを見ることで、沸騰開始を見逃していないかを確認する。

さらに、特定の周波数帯や時間帯をマスクした後にONB近傍RMSEやRecallが悪化するかを調べることで、その領域が単に可視化上目立つだけでなく、実際のONB検知に関係しているかを確認する。

## 4. 先生に相談する場合の質問候補

1. ONB近傍の主定義を、現在の熱流束基準「ONBしきい値±10%」としてよいか。
2. 早期検知の主指標を、ONB近傍RMSE、False Negative、Recallに加え、検知リードタイムとして設計してよいか。
3. 次の優先順位を、説明性出力の確認より先に元WAV単位・実験日単位の評価分割へ置くべきか。
4. RFのPCA空間TreeSHAPはモデル内部監査に限定し、物理的な主張を周波数帯・時間帯マスクへ限定する方針でよいか。
5. アンサンブルは最終精度の主役ではなく、単体モデルの見逃しや条件依存性を補えるかを検証する比較対象としてよいか。
