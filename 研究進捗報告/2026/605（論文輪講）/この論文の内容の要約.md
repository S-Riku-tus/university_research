## 1. この論文の問題意識

Transformerは、BERTやViTのように高性能ですが、内部が深く複雑なので、**なぜその予測をしたのかが分かりにくい**という問題があります。

既存の説明手法には、主に次の限界があると整理されています。

| 既存手法                     | 問題点                                                                    |
| ------------------------ | ---------------------------------------------------------------------- |
| raw attention            | attention重みをそのまま重要度と見なすが、本当に予測根拠とは限らない                                 |
| Attention Rollout / Flow | 層間のattentionの流れは見られるが、attention以外のFFN・value・残差接続などを十分扱えない              |
| Integrated Gradients     | 入力特徴の寄与は見られるが、通常は最終出力に対する入力レベルの寄与が中心                                   |
| LRP                      | relevanceを伝播できるが、multi-head attentionやLayerNormなどTransformer構造では扱いが難しい |

この論文では、特に **「最終層だけを見る説明では、Transformer内部でどのように意味・文脈・判断根拠が形成されたかが分からない」** という点を問題にしています。

---

## 2. 提案手法：CA-LIGとは何か

提案手法の名前は **CA-LIG** です。

正式には、

> **Context-Aware Layer-wise Integrated Gradients**

です。

分解すると、

| 部分                   | 意味                               |
| -------------------- | -------------------------------- |
| Context-Aware        | token同士の文脈関係、attention構造を考慮する    |
| Layer-wise           | 最終層だけでなく、各Transformer blockごとに見る |
| Integrated Gradients | baselineから入力までの勾配積分で寄与を求める       |

つまり、CA-LIGは、

> **Integrated Gradientsを各Transformer層で計算し、それをattention gradientと融合して、層をまたいだ文脈的な重要度マップを作る手法**

です。

---

## 3. Integrated Gradientsの基本アイデア

Integrated Gradientsは、入力特徴が予測にどれだけ寄与したかを求める手法です。

普通の勾配法では、入力点そのものの勾配だけを見ます。
しかし、勾配は局所的なので、勾配が小さい場所では重要度をうまく拾えない場合があります。

そこでIntegrated Gradientsでは、

> **何も情報がないbaselineから、実際の入力まで少しずつ変化させ、その途中の勾配を平均する**

という考え方を使います。

画像やスペクトログラムで言うと、

* baseline：真っ黒画像、ゼロスペクトログラム、平均スペクトログラムなど
* input：実際のスペクトログラム
* output：沸騰確率、熱流束予測値、対象クラススコア

です。

この論文では、各層の隠れ表現に対して、baselineから実際の表現まで補間し、その途中の勾配を積分して、tokenごとのrelevanceを計算します。さらに特徴次元方向に足し合わせることで、token単位の寄与を得ています。正の値は予測を支持する根拠、負の値は予測を妨げる根拠として扱われます。

あなたの研究に置き換えると、

> **スペクトログラム上の各時間–周波数領域が、沸騰判定や熱流束予測にどれだけプラス/マイナスに効いたかを見る**

ということになります。

---

## 4. この論文の手法の流れ

CA-LIGの処理は、大きく4段階です。

### Step 1：各層でIntegrated Gradientsを計算する

通常のIGは入力と出力の関係を見ますが、この論文では各Transformer blockの隠れ表現に対してIGを計算します。

これにより、

> **浅い層ではどのtokenが効いているか、深い層ではどのtokenが効いているか**

を層ごとに追えます。

Transformerでは、浅い層は局所的・表面的特徴、深い層は意味的・タスク特化的特徴を扱うことが多いため、層ごとに見ることには意味があります。

---

### Step 2：attention gradientを計算する

次に、各Transformer blockのattention重みに対して、出力スコアの勾配を計算します。

これは、

> **どのattention接続が、対象クラスの予測にどれだけ効いているか**

を見るためです。

単なるattention mapは、「どこにattentionを向けたか」しか分かりません。
一方、attention gradientを見ると、

> **そのattentionが予測結果にどれだけ影響したか**

を見られます。

この論文では、attentionは単独では説明として扱わず、Integrated Gradientsで得たtoken重要度を文脈的に分配するための補助信号として使っています。

---

### Step 3：IGのtoken重要度とattention gradientを融合する

ここがCA-LIGの中核です。

Integrated Gradientsで得られたtokenごとの重要度と、attention gradientで得られたtoken間の関係性を掛け合わせます。

つまり、

> **どのtokenが重要か**
> と
> **どのtoken同士の関係が予測に効いているか**

を同時に見るわけです。

論文では、この融合により、localなtoken重要度とglobalなattention構造を統合できると説明しています。

---

### Step 4：層をまたいでrelevanceをrolloutする

最後に、各層で得られたrelevance付きattention行列を掛け合わせて、最終的なcontext-aware attribution mapを作ります。

これにより、

> **入力tokenの影響が、Transformerの層を通じてどのように最終予測へ伝わったか**

を表現できます。

さらに、最終的なマップは正と負に分けられます。

| 符号   | 意味              |
| ---- | --------------- |
| 正の寄与 | その予測を支持する証拠     |
| 負の寄与 | その予測を弱める・反対する証拠 |

これはあなたの研究でも使いやすく、例えば、

* 正の寄与：沸騰らしさを強める時間–周波数領域
* 負の寄与：未沸騰・ノイズ・別現象として働く領域

のように解釈できます。

---

## 5. 実験内容

この論文では、NLPと画像の両方で評価しています。

| 分野                | データセット               | モデル                    |
| ----------------- | -------------------- | ---------------------- |
| 感情分析              | IMDB / Movie Reviews | BERT                   |
| 長文・多クラス分類         | 20 Newsgroups        | BERT-base / BERT-large |
| 低リソース言語のヘイトスピーチ検出 | Amharic hate speech  | XLM-R / AfroLM         |
| 画像分類              | CIFAR-10, ASIRRA     | MAE Vision Transformer |

比較手法としては、Input × Gradient、通常のIntegrated Gradients、LRP、Attention Rollout、Attention Lastなどを使っています。実験では、IGの補間ステップ数は主に50としており、25・50・100ステップで感度分析も行っています。

---

## 6. 結果の要点

結果として、CA-LIGは既存手法よりも、

* token重要度が人間の直感に近い
* attentionだけの手法より均一すぎない
* IG単体より文脈関係を反映しやすい
* 正負の寄与を分けられる
* 層ごとのrelevance変化を追える
* 画像分類でも重要領域が比較的まとまる

と主張されています。

特に画像タスクでは、Grad-CAM、LRP、IGなどと比較し、CA-LIGの方が対象物の意味的に重要な領域へ集中しやすい例が示されています。また、perturbation評価では、重要パッチを追加したときのconfidence回復が速く、重要パッチを削除したときのconfidence低下も大きいという結果が出ています。

---

## 7. この論文の限界

ただし、輪講では限界も話した方が良いです。

主な限界は次です。

| 限界             | 内容                                                |
| -------------- | ------------------------------------------------- |
| 計算コストが高い       | 各層でIGを計算するため、通常のIGより重い                            |
| encoder-only中心 | decoder型LLMでは十分検証されていない                           |
| λの調整が手動        | attention gradientとtoken relevanceの融合比率を自動で決められない |
| vision評価は限定的   | 画像タスクではまだ評価が十分とは言いにくい                             |
| 実装の再現性         | 論文ではコード公開予定とされており、完全な再現には注意が必要                    |

あなたの研究でそのままCA-LIG全部を実装するのは少し重いです。
なので、まずは **通常のIntegrated GradientsをAlexNet / Conformerに適用する** 方が現実的です。

## 8. あなたの研究との接続

あなたの研究では、沸騰音をSTFTやCWTで時間–周波数表現に変換し、AlexNetやConformerで熱流束や沸騰状態を予測しています。

この論文の考え方を使うと、次のような説明ができます。

| 論文の概念                | あなたの研究での対応                  |
| -------------------- | --------------------------- |
| token                | スペクトログラムのパッチ、時間フレーム、周波数帯    |
| target class         | 沸騰 / 未沸騰、または熱流束予測値          |
| positive attribution | 沸騰判定を強める時間–周波数領域            |
| negative attribution | 沸騰判定を弱める領域、ノイズ・背景成分         |
| layer-wise relevance | Conformer内部でONB特徴がどの層で強くなるか |
| attention gradient   | どの時間フレーム間の関係が予測に効いているか      |

特にあなたの研究では、以前から **Grad-CAM、Integrated Gradients、attention map、マスク実験を用いて、各モデルがどの時間–周波数領域を根拠としているかを見る** 方向で整理しています。

そのため、この論文はかなり自然につながります。

---

## 9. 輪講での中心メッセージ

発表では、次の一文を中心にすると良いです。

> **この論文は、Transformerの説明性において、attention mapだけでは不十分であるという問題に対して、Integrated Gradientsを各層に拡張し、attention gradientと融合することで、局所的な入力寄与と層間・文脈的な情報流を同時に説明しようとする研究である。**

あなたの研究への接続としては、

> **沸騰音スペクトログラムに対してIGを適用すれば、ONB近傍でどの時間–周波数領域が予測に効いたかを可視化できる。さらにConformerでは、層ごとのIGやattention gradientを見ることで、局所的な気泡音特徴と時間的文脈のどちらを根拠にしているかを解析できる。**

とまとめると良いです。
