## スライド6：研究背景

スライドに載せる要素：
- Transformer（BERT・ViT）は高性能だが、**内部が深く、なぜその予測をしたかが分かりにくい**
- 医療・低リソース言語・安全性が関わる場面では、**予測根拠の説明（XAI）が不可欠**
- 図：Transformer の簡単な模式図（入力 token → 複数の層 → 予測）を自作。最後の予測だけ見ても途中が分からない、という矢印を添える。

話す内容：
> Transformer は高い性能を出しますが、層が深く構造が複雑なため、予測の根拠が分かりにくいという問題があります。
> 特に判断の妥当性が問われる場面では、どの入力を根拠にしたかを説明できることが重要になります。

---

## スライド7：既存 XAI 手法の課題（比較表）

**前回の「従来手法の課題」と同じく比較表で見せる。**

| 既存手法 | できること | 課題 |
| --- | --- | --- |
| raw attention | attention 重みを重要度として可視化 | 重み＝予測根拠とは限らない |
| Attention Rollout / Flow | 層間の attention の流れを追える | FFN・value・残差接続を扱えない |
| Integrated Gradients | 入力特徴の寄与を求められる | 通常は**最終出力・入力レベル中心**で層内部が見えない |
| LRP | relevance を逆伝播できる | multi-head attention や LayerNorm で扱いが難しい |

話す内容：
> 既存の説明手法にはそれぞれ限界があります。attention をそのまま重要度と見なす方法は根拠とは限らず、
> rollout は attention 以外を扱えません。Integrated Gradients は入力寄与は見られますが、通常は最終層中心です。
> つまり**「最終層だけの説明では、層をまたいでどう文脈・根拠が形成されたかが分からない」**——これがこの論文の問題意識です。

スライド下部に一文（強調）：
> 課題：**最終層だけの説明では、Transformer 内部で根拠がどう形成されたかが分からない**

## スライド11：手法 – Integrated Gradients の基本

スライドに載せる要素：
- 通常の勾配は局所的で、勾配が小さい所で重要度を拾い損ねる
- IG は **baseline から実入力まで少しずつ変化させ、経路上の勾配を積分**する
- 式（簡略形）：
  > IG ＝（入力 − baseline）× 経路上の平均勾配
- 図：baseline（真っ黒画像／ゼロスペクトログラム）→ input への矢印を自作
- 自分の研究への置き換え（小さく一言）：
  > baseline＝ゼロ/平均スペクトログラム、input＝実スペクトログラム、output＝沸騰確率・熱流束

話す内容：
> Integrated Gradients は、何も情報がない baseline から実際の入力まで経路を引き、その途中の勾配を積分して寄与を求めます。
> 自分の研究なら、ゼロスペクトログラムから実際のスペクトログラムへ変化させ、どの時間–周波数領域が熱流束予測に効いたかを見る、というイメージです。

---

## スライド12：手法 – Step1 Layer-wise IG

スライドに載せる要素：
- 通常の IG は入力のみ。CA-LIG は**各層の隠れ表現**に IG を適用
- 各層で baseline 表現→実表現を補間し、対象クラススコアへの勾配を積分 → token relevance
- 特徴次元方向に足し合わせて token 単位の寄与に
- 浅い層＝局所的・表面的特徴、深い層＝意味的・タスク特化的特徴

話す内容：
> Step1 では IG を入力だけでなく各層の隠れ表現に適用します。
> これにより、token の重要度が浅い層から深い層へどう変化するかを層ごとに追えます。

---

## スライド13：手法 – Step2 Attention Gradient

スライドに載せる要素：
- attention 重みそのものではなく、**その attention が対象クラス出力にどれだけ効いたか**（出力スコアの attention に対する勾配）
- 「attention を向けた場所」ではなく「予測に効いた attention」を見る
- 論文では attention 単独を説明とせず、IG の token 重要度を**文脈的に分配する補助信号**として使う

話す内容：
> Step2 では attention 重みに対する出力の勾配を計算します。
> 単なる attention map は「どこを見たか」しか分かりませんが、attention gradient は「その接続が予測にどれだけ効いたか」を表します。

---

## スライド14：手法 – Step3 IG × Attention Gradient の融合

**ここが手法の核。** 貼る図：**Fig.1 の Stage2 部分を拡大**。

スライドに載せる要素：
- IG：**どの token が重要か**（局所寄与）
- Attention gradient：**どの token 間関係が予測に効いているか**（文脈構造）
- CA-LIG：この2つを融合 → 局所寄与と文脈関係を同時に説明
- 融合比率 λ で重み付け（後の限界スライドで「手動調整」に触れる）

話す内容：
> Step3 が核心です。IG で得た token ごとの重要度と、attention gradient で得た token 間の関係性を掛け合わせます。
> これにより local な重要度と global な文脈構造を一つのマップに統合できます。

---

## スライド15：手法 – Step4 層をまたぐ rollout

スライドに載せる要素：
- 各層の relevance 付き attention 行列を掛け合わせ、最終的な **context-aware attribution map** を作る
- 入力 token の影響が層を通じて最終予測へどう伝わったかを表現
- 出力は**正負に分けられる**：

| 符号 | 意味 | 自分の研究での解釈 |
| --- | --- | --- |
| 正の寄与 | 予測を支持する証拠 | 沸騰らしさを強める時間–周波数領域 |
| 負の寄与 | 予測を弱める証拠 | 未沸騰・ノイズ・別現象として働く領域 |

話す内容：
> 最後に各層の relevance 付き attention を掛け合わせて、入力の影響が層を通じてどう最終予測に伝わったかを表すマップを作ります。
> 寄与は正負に分けられ、自分の研究なら「沸騰を強める領域」と「弱める／ノイズ領域」として解釈できます。

## スライド21：限界

スライドに載せる要素（表）：

| 限界 | 内容 |
| --- | --- |
| 計算コストが高い | 各層で IG を計算するため通常の IG より重い |
| encoder-only 中心 | decoder 型 LLM では未検証 |
| λ が手動調整 | 融合比率を自動で決められない |
| vision 評価が限定的 | 画像タスクの評価はまだ十分でない |
| 再現性 | コードは公開予定で完全再現には注意 |

話す内容：
> 限界としては、各層で IG を計算するため計算コストが高いこと、encoder-only 中心で decoder 型には未検証なこと、
> 融合比率 λ が手動なこと、画像評価が限定的なことが挙げられます。
> 自分の研究で CA-LIG を丸ごと実装するのは重いので、まずは通常の IG から始めるのが現実的だと考えています。

自分の研究への活用（論文概念→自研究の対応表）：

| 論文の概念 | 自分の研究での対応 |
| --- | --- |
| token | スペクトログラムのパッチ／時間フレーム／周波数帯 |
| target class | 沸騰／未沸騰、または熱流束予測値 |
| positive attribution | 沸騰判定を強める時間–周波数領域 |
| negative attribution | 弱める領域・ノイズ・背景成分 |
| layer-wise relevance | Conformer 内部で ONB 特徴がどの層で強くなるか |
| attention gradient | どの時間フレーム間の関係が予測に効くか |

活用ステップ（話す内容）：
> まず通常の Integrated Gradients を AlexNet・Conformer に適用し、STFT/CWT 上の時間–周波数寄与を可視化します。
> 次に重要領域を時間・周波数マスクして、予測熱流束や沸騰判定が変化するかを確認します。
> 将来的には Conformer の層ごとの IG や attention gradient を使い、ONB 近傍の特徴がどの層で形成されるかを解析したいと考えています。

締めの一文：
> **この論文の考え方を使えば、沸騰音スペクトログラム上で「どの時間–周波数領域が、どの層で、沸騰判定にプラス/マイナスに効いたか」を説明できる。**
