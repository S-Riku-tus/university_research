## スライド7：既存XAI手法の課題

- **レイアウト**：比較表型（リード文＋比較表）
- **リード文**：**既存のXAI手法はそれぞれ「できること」と「課題」がある**
- **本文**：

  | 手法 | できること | 課題 |
  | --- | --- | --- |
  | raw attention | attention重みを重要度として可視化 | 重み＝予測根拠とは限らない |
  | Attention Rollout / Flow | 層間のattentionの流れを追える | FFN・value・残差接続を扱えない |
  | Integrated Gradients | 入力特徴の寄与を求められる | 最終出力・入力レベル中心で層内部が見えない |
  | LRP | relevanceを逆伝播できる | multi-head attention・LayerNormで扱いが難しい |

  > ➡ いずれも **最終層だけ／入力寄与だけ／attention構造だけ** に偏りがち
- **図**：なし
- **話す内容**：
  > 既存の説明手法には、それぞれ限界があります。raw attentionは重みをそのまま重要度と見なしますが、重みが必ずしも予測根拠とは限りません。Attention Rolloutは層間の流れを追えますが、FFNやvalue、残差接続を扱えません。Integrated Gradientsは入力寄与を見られますが、通常は最終出力や入力レベルが中心で層の内部が見えません。LRPはrelevanceを逆伝播できますが、multi-head attentionやLayerNormでは扱いが難しいです。つまり、最終層だけの説明では内部で文脈や根拠がどう形成されたかが分からない、というのがこの論文の問題意識です。

## スライド8：目的・新規性

- **レイアウト**：目的型（リード文 ＋ ▌定義(箇条書き) ＋ ▌目的(ボックス1文) ＋ ▌新規性(ボックス内⚫)）
- **リード文**：**Integrated Gradients を各層に拡張し attention gradient と融合 ── 局所的な入力寄与と層・文脈情報を同時に説明する。**
- **本文**：
  > **▌定義：CA-LIG = Context-Aware / Layer-wise / Integrated Gradients**
  >
  > - ⚫ **Context-Aware** ── token 同士の文脈関係（attention 構造）を考慮
  > - ⚫ **Layer-wise** ── 最終層だけでなく各 Transformer block を見る
  > - ⚫ **Integrated Gradients** ── baseline→入力の勾配積分で寄与を求める（本手法では各層の隠れ表現へ拡張）
  >
  > **▌目的**
  >
  > > 〔ボックス〕Integrated Gradients を各 Transformer 層で計算し、attention gradient と融合して、層をまたいだ文脈的な重要度マップを作る
  >
  > **▌新規性**
  >
  > > 〔ボックス〕
  > > - ⚫ IG を**入力だけでなく各層の隠れ表現**へ拡張（Layer-wise）
  > > - ⚫ token 重要度（local）と attention gradient の文脈構造（global）を**融合**
  > > - ⚫ 層をまたぐ rollout で**入力→予測の根拠形成**を追跡
  > > - ⚫ 寄与を**正負に分離**（支持する根拠／妨げる根拠）
- **図**：なし
- **話す内容**：
  > 提案手法は CA-LIG、正式には Context-Aware Layer-wise Integrated Gradients です。名前を3つに分けると、Context-Aware が token 同士の文脈関係を考慮すること、Layer-wise が各 Transformer block を見ること、Integrated Gradients が baseline から入力までの勾配積分で寄与を求めることを表します。通常の IG は入力レベルの寄与を見ますが、本手法ではこれを各層の隠れ表現へ拡張している点が異なります。目的は、この IG を各層で計算し attention gradient と融合して、層をまたいだ文脈的な重要度マップを作ることです。新規性は、IG を各層へ拡張し、token の局所的な重要度と attention の文脈構造を融合する点、さらに層をまたぐ rollout で根拠の形成過程を追え、寄与を正負に分離できる点にあります。一言でいえば、局所的な入力寄与と層をまたいだ文脈情報を同時に説明できることが新しさです。
- **体裁メモ**：CA-LIGの3語分解は「手法間の比較」ではなく用語定義なので、**比較表ではなく⚫箇条書き**にした（v1の表を修正）。

## スライド10：手法 – CA-LIG の全体像

- **レイアウト**：全体像／図中心型（Fig.1を中央に大きく1枚）
- **リード文**：CA-LIG は 4 ステップで、層をまたいだ文脈的な寄与マップを作る。
- **本文**：
  > ➡ **Step1 Layer-wise IG** → **Step2 Attention Gradient** → **Step3 融合** → **Step4 層間 rollout**
  >
  > - ⚫ **Step1 Layer-wise IG**：各 Transformer block の隠れ表現に IG を適用し token relevance を計算
  > - ⚫ **Step2 Attention Gradient**：attention 重みに対する対象クラス出力の勾配を計算
  > - ⚫ **Step3 融合**：token 重要度と attention gradient を掛け合わせ、局所寄与と文脈構造を統合
  > - ⚫ **Step4 層間 rollout**：各層の relevance 付き attention を掛け合わせ、context-aware attribution map を合成
  >
  > ※ Fig.1 は3ステージ表記。図の **Stage1 = Step1+Step2**、**Stage2 = Step3**、**Stage3 = Step4** に対応。
- **図**：**Fig. 1（p.5）** CA-LIG 全体アーキテクチャ（Input→Block1→…→BlockB→出力 y_c の流れに Stage1/2/3 を図示）。中央に大きく配置。
- **話す内容**：
  > CA-LIG の処理は大きく4ステップに分かれます。Step1 で各 Transformer block の隠れ表現に Integrated Gradients を適用して token ごとの重要度を求め、Step2 で attention 重みに対する出力の勾配、つまり attention gradient を計算します。Step3 でこの2つを融合し、Step4 で層をまたいで rollout することで、最終的な文脈的な寄与マップを作ります。なお論文の Fig.1 は3つの Stage で描かれていて、図の Stage1 が Step1 と Step2、Stage2 が Step3 の融合、Stage3 が Step4 の rollout に対応します。この後はまず Integrated Gradients の基本から説明します。
- **体裁メモ**：図（3 Stage）と説明（4 Step）の段数が違うので、対応関係を本文末1行＋口頭で明示して聴衆の混乱を防ぐ。

## スライド11：手法 – Integrated Gradients の基本

- **レイアウト**：図左＋箇条書き右型（図は自作）
- **リード文**：IG は baseline から実入力までの経路上の勾配を積分して寄与を求める。
- **本文**：
  > **▌基本アイデア**
  > - ⚫ 通常の勾配は局所的 ➡ 勾配が小さい所で重要度を拾い損ねる
  > - ⚫ IG は baseline から実入力まで少しずつ変化させ、経路上の勾配を積分
  >
  > **▌式（簡略形）**
  > > 〔ボックス〕**IG ＝（入力 − baseline）× 経路上の平均勾配**
  >
  > - ⚫ baseline 表現→実表現へ補間し、対象クラススコアへの勾配を積分
  >   - ➢ 特徴次元方向に足し合わせ → token 単位の寄与
  >   - ➢ 正＝予測を支持／負＝予測を妨げる
  >   - ➢ ※ これを各 Transformer 層へ拡張するのが Step1（次スライド）
  >
  > **▌自分の研究への置き換え**
  > - ⚫ baseline＝ゼロ/平均スペクトログラム、input＝実スペクトログラム、output＝沸騰確率・熱流束

## スライド12：手法 – Step1 Layer-wise IG

  > - ⚫ token relevance が浅層→深層でどう変化するか追える

## スライド14：手法 – Step3 IG × attention gradient の融合 ★核心

- **レイアウト**：図左＋箇条書き右型（Fig.1 Stage2拡大）
- **リード文**：**ここが CA-LIG の核心。local な token 重要度と global な文脈構造を 1 枚に統合する。**
- **本文**：
  > **▌融合する 2 つの信号**
  > - ⚫ Integrated Gradients（token relevance）
  >   - ➢ どの token が重要か = 局所寄与（local）
  > - ⚫ attention gradient
  >   - ➢ どの token 間関係が予測に効くか = 文脈構造（global）
  >
  > **▌融合（Stage2）**
  > - ⚫ attention gradient ⊙ token relevance → 残差接続を保持
  > - ⚫ multi-head 方向に統合 → relevance 付き attention 行列
  >
  > ➡ **local な重要度と global な文脈を同時に説明**
  >
  > - ⚫ 融合比率 **λ**（0〜1）で attention gradient をどれだけ効かせるかを調整
  >   - ➢ λ=0 なら token relevance のみ／λ は手動調整（後述の限界で言及）
- **図**：**Fig. 1（p.5）の Stage2 部分を拡大**（attention gradient と token relevance の融合ブロック）。左に配置。
- **話す内容**：
  > Step3 がこの手法の核心です。Integrated Gradients で得た token ごとの重要度と、attention gradient で得た token 間の関係性を掛け合わせます。これにより、どの token が重要かという局所的な寄与と、どの token 同士の関係が予測に効くかという文脈構造を、一つのマップに統合できます。融合の比率は λ というパラメータで決まり、λ を大きくするほど attention gradient の影響が強まり、λ=0 では token relevance だけになります。ただしこの λ は手動調整であり、後ほど限界として触れます。
- **体裁メモ**：論文式(7) `Ā^(b)=M_h[λ(∇A⊙Norm(R))+(1-λ)Norm(R)]+I` に基づき λ の説明を精緻化（IG信号 vs attention gradient信号の単純比率、ではない）。
