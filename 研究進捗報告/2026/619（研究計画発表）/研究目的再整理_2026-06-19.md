# 研究目的の再整理 2026-06-19

## このメモの位置づけ

このメモは、2026年6月19日の研究計画発表に向けて、研究目的の書き方を整理するためのものである。

これまでの資料では、「音響データを用いて熱流束を回帰し、ONB閾値で沸騰開始点近傍を検知する」「ノイズ下でも利用できるかを明らかにする」「評価する」といった表現が多かった。しかし、これらは手段や確認作業に近く、研究目的として置くと、目的と手段が混ざって見える。

特に、「ONB近傍の音響特徴を検知根拠として利用できるかを明らかにする」という表現は、卒論で示した基本的成立性に戻ってしまう可能性がある。卒論ではすでに、音響スペクトログラムから熱流束を回帰し、予測熱流束をONB閾値で二値化することで、沸騰発生検知が可能であることを示している。修士研究では、その成立性を前提に、より信頼できる検知構成へ進める必要がある。

したがって、ここでは研究目的を「評価すること」ではなく、評価を通じて何につなげるのかまで含めて整理する。

## 背景

高速炉などの冷却系では、冷却状態の変化や異常兆候を早期に把握することが重要である。沸騰開始や気泡発生は、熱伝達状態の変化に関わるため、異常兆候を捉える手がかりになり得る。

音響計測は、非接触または外部取り付けで利用できる可能性があり、温度・圧力などの従来計測とは異なる診断情報を得られる可能性がある。一方で、実際の計測環境では水流動音、装置由来のノイズ、構造振動などが重なるため、清浄な音響データだけで成立する検知では不十分である。

また、安全監視や物理現象の理解に使うことを考えると、平均精度だけでなく、モデルが何を根拠に判断しているかを説明できることも重要である。

## 卒論で示したこと

卒論および原子力学会発表では、主に次のことを示した。

- STFTスペクトログラムをCNN系モデルに入力し、熱流束を回帰予測できること。
- 予測熱流束をONB閾値で二値化することで、沸騰発生検知を評価できること。
- AlexNet、ResNet50、VGG16の重み付き平均アンサンブルにより、単体モデルよりノイズ下で性能劣化を抑えられる傾向があること。
- 100%分類可能な熱流束下限を、ONBから限界熱流束までの相対位置として評価し、早期検知の可能性を示したこと。

このため、修士研究の目的を「音響データを検知に利用できるか」と置くと、卒論との差分が弱くなる。

## 残っている課題

卒論で基本的成立性は示したが、修士研究としては次の課題が残っている。

- ONB近傍の音響変化は微弱で、発達した沸騰状態に比べて特徴が弱い。
- 気泡発生に伴う音は非定常であり、単純な音圧や単一周波数の閾値では捉えにくい。
- 水流動音などのノイズが沸騰音と重なり、スペクトログラム上でも単純に分離できない可能性がある。
- 全体の熱流束回帰精度が高くても、ONB閾値付近で予測が少しずれると、見逃しや誤検知につながる。
- 単体モデルは、特定のノイズ条件、fold、実験条件、データセット固有の癖に依存する可能性がある。
- アンサンブルで平均精度が上がっても、改善がノイズやデータセット固有の特徴に基づいている場合、信頼できる検知手法とは言いにくい。

したがって、修士研究では「当たるかどうか」だけでなく、「どの条件で安定するか」「どの構成なら見逃しや検知遅れを抑えられるか」「その判断根拠を物理現象と対応づけて説明できるか」を整理する必要がある。

## 研究目的

本研究の目的は、音響データに基づく熱流束回帰を用いたプール沸騰開始点近傍検知について、ノイズ下でも性能劣化や予測ばらつきを抑え、沸騰現象に対応した根拠で判断していると説明できるモデル構成・統合方法・評価条件を整理することである。

言い換えると、本研究では、熱流束回帰モデルを単に高精度化することではなく、ONB近傍検知に対して信頼できる構成を選ぶための判断基準を作ることを目指す。

ここでの「信頼できる構成」とは、次の条件を満たす構成を指す。

- ノイズが増加しても、熱流束回帰やONB検知の性能劣化が小さい。
- 単体モデルだけに依存した予測ばらつきが小さい。
- ONB近傍での見逃しや検知遅れを抑えられる。
- 重要とされる時間・周波数領域が、沸騰現象に関係する特徴と矛盾しない。
- 実験条件や分割方法を変えたときに、性能や判断根拠が大きく崩れにくい。

## 評価は何のために行うか

評価は、評価そのものを目的として行うのではない。ONB近傍検知において、どのモデル構成・統合方法・入力表現を採用すべきかを判断するために行う。

具体的には、各評価は次の役割を持つ。

| 評価すること | 目的へのつながり |
| --- | --- |
| 全体回帰性能 | 熱流束回帰モデルとして最低限成立しているかを確認する |
| ONB近傍誤差 | 平均精度に隠れたONB閾値付近の弱さを確認する |
| 見逃し率・Recall | 早期検知で避けたい見逃しを抑えられるか確認する |
| 検知遅れ | ONB近傍でどの程度早く反応できるか確認する |
| SNR別性能・劣化率 | ノイズ増加時に性能がどの程度落ちるか確認する |
| fold別・seed別ばらつき | 特定の分割や初期値に依存していないか確認する |
| 単体モデルと統合モデルの差 | アンサンブル統合が何を補っているか確認する |
| 時間・周波数マスク | 重要領域が予測に実際に影響しているか確認する |
| Grad-CAM / IG / RISEなど | モデルが見ている領域を可視化し、物理的妥当性の検討材料にする |

このように、評価は「良い点数を出すため」ではなく、ノイズ下・ONB近傍で使うべき検知構成を選ぶための根拠を作るために行う。

## アンサンブル統合の位置づけ

アンサンブル統合は、ONB検知ロジックそのものではない。基本の流れは、各モデルが音響データから熱流束を回帰し、その予測熱流束を必要に応じて統合し、最後にONB閾値で判定することである。

本研究におけるアンサンブル統合の役割は、次の4点である。

1. ノイズ耐性の強化  
   SNRが低下したときに、単体モデルより性能劣化を抑えられるかを確認する。

2. 予測ばらつきの低減  
   fold、seed、ノイズ条件、入力表現の違いによって単体モデルの予測が揺れる場合に、統合によって安定化できるかを確認する。

3. ONB近傍の見逃し・検知遅れの低減  
   全体R2が高いだけではなく、ONB閾値付近で判定が安定するか、見逃しや検知遅れを減らせるかを確認する。

4. 異なる特徴の補完  
   CNN系、CNN+Transformer系、RandomForest系など、異なる特徴を捉える可能性のあるモデルを組み合わせることで、単体モデルの弱点を補えるかを確認する。

したがって、アンサンブル統合を使う理由は「平均精度を上げるため」だけではない。特に、ノイズ下での性能劣化、ONB近傍での判定の揺れ、単体モデル依存の不安定性を抑えるための手段として位置づける。

## 6/19発表スライド用の短縮版

6/19発表の「研究目的の再構成」スライドでは、次のように書くと目的と手段が分かれやすい。

```text
目的:
音響データに基づく熱流束回帰を用いた
プール沸騰開始点近傍検知について、
ノイズ下でも性能劣化や予測ばらつきを抑え、
物理現象と対応づけて説明できる検知構成を整理する。

確認すること:
- ノイズ増加時に、熱流束回帰・ONB検知性能の劣化を抑えられるか
- 複数モデル統合により、単体モデル依存の予測ばらつきを抑えられるか
- ONB近傍の見逃し・検知遅れを低減できるか
- 重要な時間・周波数領域が沸騰現象と対応しているか
```

口頭では、次のように説明できる。

> 卒論では、音響スペクトログラムから熱流束を回帰し、ONB閾値で沸騰発生を検知できる可能性を示しました。修士では、その成立性を前提として、ノイズが増えた場合やONB近傍の微弱な変化に対して、どのモデル構成や統合方法が安定して使えるのかを整理したいと考えています。特に、アンサンブル統合を単なる平均精度向上ではなく、ノイズ耐性、予測ばらつきの低減、ONB近傍の見逃し・検知遅れの低減という観点から位置づけます。そのうえで、改善が沸騰現象に関係する時間・周波数特徴に基づいているかも確認します。

## 今後の相談事項

- 研究目的を「利用できるかを明らかにする」ではなく、「信頼できる検知構成と判断基準を整理する」と置いてよいか。
- ONB近傍の主定義は、熱流束基準、時間基準、サンプル基準のどれを中心にすべきか。
- ノイズ耐性は、SNR別性能、no_noiseからの劣化率、未知ノイズ条件への汎化のどれを主に見るべきか。
- アンサンブル統合の重みは、全体回帰性能、ONB近傍性能、高ノイズ条件での安定性のどれを基準にすべきか。
- 説明性評価は、可視化図だけでなく、時間・周波数マスクによる予測変化まで確認する方針でよいか。
