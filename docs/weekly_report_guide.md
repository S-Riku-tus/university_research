# 週次研究進捗報告ガイド

## 基本形式

植木研の週次報告はSOAP形式で作る。

- `S: Subjective`: 現在考えていること、問題意識、悩んでいること、検討中の仮説。
- `O: Objective`: 実際に行った作業、得られた結果、確認した事実。
- `A: Assessment`: 結果の解釈、課題の整理、研究上の意味づけ。
- `P: Plan`: 次週やること、短期目標、中期的な計画、相談したいこと。

## 書き方の方針

- Sには、研究の方向性や迷っている論点を書く。
- Oには、コード実行、モデル変更、図作成、論文調査、資料作成などの客観的な作業を書く。
- Aには、Oから何が言えるか、何がまだ弱いかを書く。
- Pには、次に何をやれば研究が前に進むかを書く。
- 「やっていない週」でも、Sに考えていることを書き、Pに次の確認事項を書く。

## Codexで下書きを作る手順

1. `docs/research_context.md` を読む。
2. `docs/progress_index.md` の直近2件を読む。
3. `git status --short` と最近更新されたファイルを確認する。
4. 必要に応じて中心コードや直近報告書の本文を読む。
5. `templates/weekly_progress_SOAP.md` の形式で下書きを作る。
6. 最後に、研究上の問いと次週の行動が対応しているか確認する。

## 下書きで優先する内容

- 研究目的に対して今週の作業がどう関係するか。
- モデルやデータ処理を変えた場合、その意図。
- 結果が出ている場合、数値だけでなく解釈。
- 結果が出ていない場合、次に確認すべき条件。
- 先生に相談したい判断ポイント。

## 避けること

- 「勉強した」「調べた」だけで終わること。
- 精度の数値だけを書いて、なぜそうなったかを書かないこと。
- 次に何をするかが曖昧なまま終わること。
- 過去の報告と同じ内容を、進展なしに繰り返すこと。
