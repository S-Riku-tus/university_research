# 研究コンテキスト

## 研究目的

本研究は、プール沸騰実験で得られる音響データから熱流束を回帰し、その予測値を用いて沸騰開始点近傍を早期に検知することを目的とする。特に、単に高い予測精度を得るだけでなく、どの時間・周波数特徴が熱流束予測やONB近傍検知に寄与しているかを説明できる形にすることを重視する。

2026年6月19日の研究計画発表後は、RandomForestの高性能を重要な結果として扱いつつも、どれか1つのモデルを主軸として固定しない方針に修正した。CNN+TransformerやAlexNetは学習設定がまだ十分に最適化されていない可能性があるため、各モデルの入力前処理、学習条件、評価、説明性を整えたうえで比較する。

## 現在の問題意識

- 学部研究との差分を明確にする必要がある。
- 単に精度が高いだけでなく、物理現象に即した判断をモデルができているかを説明したい。
- 沸騰開始点近傍で見られる離散的な特徴を、入力表現やモデル構造がどう扱うかを見たい。
- 強ノイズ下や条件変化下でも、検知性能が維持されるかを確認したい。
- 現在のRandomForestの高い性能が、評価分割、PCA、ノイズ付与、熱流束ラベルの離散性に依存していないかを確認したい。
- CNN+TransformerやAlexNetは、入力正規化、log変換、学習率、early stoppingなどの設定が性能を大きく左右する可能性があるため、チューニング後に比較したい。
- PCA後の特徴量は元の時間・周波数位置に直接対応しにくいため、RandomForestでは周波数帯 x 時間窓のような解釈可能特徴への置き換えも検討したい。
- アンサンブル学習は、各モデルの性能と説明性を整理した後に、単体モデル依存の不安定性を下げられるかを見る上積みとして位置づけたい。

## 研究の大まかな流れ

1. 実験音声を取得する。
2. ハイパスフィルタやノイズ付与などの前処理を行う。
3. STFTなどでスペクトログラムまたは `.npy` 特徴量を作る。
4. 熱流束値を教師ラベルとして回帰モデルを学習する。
5. 予測熱流束を閾値で二値化し、沸騰/非沸騰の判定性能も評価する。
6. CNN系、CNN+Transformer系、RandomForest系の各モデルで回帰性能とONB近傍性能を確認する。
7. R2, RMSE, MAE, ONB近傍誤差、見逃し率、100%分類可能な熱流束下限、検知遅れなどから性能を整理する。
8. 回帰SHAP、周波数帯マスク、時間マスク、Grad-CAM、RISEなどでモデルの判断根拠を調べる。
9. 各モデルの性能と説明性を整理した後、必要に応じてアンサンブル予測を比較・上積みとして検証する。

## 主なモデル

- CNN系: AlexNet, VGG16, ResNet50など。
- CNN+Transformer系: スペクトログラム特徴をCNNで抽出し、Transformer Encoderで系列的に処理する。
- RandomForest系: PCAで次元削減した特徴量を使う構成が現時点で高性能。説明性を考えて、周波数帯 x 時間窓のような解釈可能特徴への置き換えも検討する。
- 今後検討候補: Conformer, SELDnet, WaveNet, 説明可能性手法との組み合わせ。

## 重要な評価観点

- 熱流束回帰の精度。
- 沸騰開始点の検知性能。
- ノイズ条件に対する頑健性。
- モデルが時間方向・周波数方向のどちらの特徴を使っているか。
- 物理的に説明できる特徴に基づく予測になっているか。

## 直近の研究上の問い

- 修士研究として、学部研究から何を新規性として積み上げるか。
- RandomForestの高い性能が本当に妥当か、どの条件で崩れるか。
- CNN+TransformerやAlexNetは、入力前処理や学習率調整でどこまで改善するか。
- no_noiseよりノイズあり条件の性能が高くなる原因は何か。
- PCAを挟んだ特徴量を主軸にしてよいか、解釈可能特徴へ移行すべきか。
- 各モデルに対する説明性評価で、物理的に説明できる寄与を示せるか。
- CNN, CNN+Transformer, RandomForest, アンサンブルを、どの評価軸で公平に比較するか。
- 実験条件数やONB近傍の刻み幅をどの程度確保すべきか。
