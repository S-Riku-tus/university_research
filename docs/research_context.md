## 研究目的

プール沸騰実験の音響信号から熱流束を回帰予測し、その予測値でONB（核沸騰開始）近傍を検知する。どの時間・周波数特徴が予測や検知に寄与し、ノイズや条件変更の下でも物理的に説明できる根拠かを調べる。

学部研究で調べた「スペクトログラムとCNN回帰による沸騰検知の基本的成立性」から、修士研究では、**なぜ・どの条件で信頼できる検知になるか**へ進める。水を用いたプール沸騰の基礎研究であり、実機ナトリウム炉で検証した成果とは区別する。

根拠は[研究計画の基本となる考え方](../研究進捗報告/研究計画の基本となる考え方_柴崎陸.docx)、[2026年度研究指導計画書](../研究進捗報告/2026_AE＿植木研＿8125517＿柴崎陸.docx)、[7/24中間発表](../研究進捗報告/2026/724（中間発表）/研究進捗_柴崎陸_0724.pptx)。

## 研究で答える問い

1. 音響から熱流束とONB近傍を、どの条件まで予測・検知できるか。
2. 各モデルはどの時間・周波数特徴を利用し、その説明は数値的・物理的に妥当か。
3. 既知WAVの未使用chunk、学習と異なるノイズ、学習に未使用の新しい実験日で何が変わるか。9/29には未知日を必須条件から外したが、**10/8の本人指示で新実験の未知日適用と物理的特徴の検討を現在の最優先へ戻した**。確認済みの旧評価範囲と、新日の未検証性能を分ける。
4. 単体とアンサンブルで、回帰精度・ONB見逃し・ノイズ下の安定性がどう変わるか。

アンサンブルは予測を安定させるための検証対象。RF、深層モデル、統合方式のどれが最終的に勝つかを先に決めない。6/19の[方針整理](research_plan/2026-06-19_after_presentation.md)に沿い、各モデルの学習条件・評価・説明性を整えて比較する。

## 確認済みの6月データ主比較の流れ

元WAV・実験の熱流束ラベル → 500 Hz高域通過・固定基準の水流音付与 → 1秒STFT power、3 kHz・224×224×1 → **6/11＋6/18の各WAV内で学習45/評価15 chunkへ分割、計1620/540、選別なし** → clean学習側shuffle chunk3-fold OOFでモデル比較・統合重みfit → clean学習の保存モデル/前処理/重みを全7雑音条件へ固定適用 → 予測熱流束（W/m²）、日別ONB判定とq100、入力依存の検証。

主比較は従来のRF・CNN＋Transformer・AlexNetに、音響34要約特徴のHGB/ExtraTreesを追加した5と、元3/4/単体の対照。元3内部比率固定と元3総量25%以上・追加各5%以上は、AIが採用した比較条件であり、本人のモデル構成保持とは区別する。既知WAVの別chunkを評価する設計であり、未知録音・未知日の性能ではない。

**現在の新実験**：`2026.10.07_0.3_1`は[10/9確認](../experiments/2026-10-09_new_experiment_generation_audit/verification.json)で5帯域・両時間長・無雑音＋6雑音の全70条件、NPY/PNG各69300が揃った。全件対応/ラベル/雑音記録、代表630組の内容、元WAV再計算24例を確認した。モデル性能は未検証。通常ONBは新日内75/25%・7雑音指定なので、そのまま未知日評価とは呼ばず、旧保存fitの固定適用または旧日学習/新日評価の別日設定を整える。全7条件の入力は生成済みで、まず無雑音の別日適用を優先する。

**9/16の本人指定（履歴）**：学習6/11+7/9、テスト6/18、学習内は学部と同じ通常chunk KFold。[当時の実装と根拠](../experiments/2026-09-16_day_split_spectral_selection/README.md)。以後の本人の範囲変更・比較・採用により、現在は上段の既知WAV内評価を使う。7/9や別日を現在の必須runへ自動追加しない。

**選別の意図と判断**：2,100–2,500 Hz内のピーク高さによる学習側選別は[実装・探索](../experiments/2026-09-16_peak_height_selection/README.md)と[3 seed比較](../experiments/2026-09-20_c_selection/README.md)を完了し、近傍誤差等の悪化から現行は不採用。静かな秒を未沸騰・誤ラベルとは断定しない。以前のONB前分位点ルールも履歴として保持する。

- 現行データ仕様は[waterflow_20260817_1s](../configs/datasets/waterflow_20260817_1s.yaml)。
- 入力配列は時間×周波数×channel。図では横軸時間、縦軸周波数。
- RFの実体はXGBRFRegressor。flatten→学習側だけでPCAをfit。
- CNN＋TransformerとAlexNetはモデル先頭で絶対強度差を残すlog-power変換を行う。
- HGB/ExtraTreesは同じ生powerから固定34音響特徴を作る保存Pipelineを使う。時間powerの変動係数を含むが、時間順序を使う特徴ではない。
- 熱流束のscalerは学習側のみでfitし、予測を元の単位へ戻す。

## 評価の用語

| 用語 | 意味・注意 |
|---|---|
| chunk | 元WAVから切り出した1秒。別chunkでも元録音が同じなら独立録音ではない |
| OOF | その標本を学習に使っていないfoldから得た予測 |
| chunk指標 | 1秒chunkの学習外予測から計算する指標。540 chunkの集計と日別/領域別を区別し、540を独立録音数としない |
| ONB近傍 | 現在は閾値±10%の暫定帯域。点数と正解の出典を併記 |
| reference SNR | 全体の固定基準RMSに対するノイズ設定。各WAVの実現SNRとは異なる |
| matched | 学習と評価のノイズ条件を合わせ、条件ごとに再学習 |
| clean_only | cleanで学習した同じモデルを各評価ノイズへ適用 |
| leave_one_day_out | ある実験日全体を学習から除いて評価。既存3日は開発で参照済み |
| explicit_days | configで指定した学習日だけでfitし、指定した別日を全区間評価する |
| performance_kfold | 内部OOFの単体R²から逆誤差重みを決める従来対照。現行の元3/4/5主比較はclean OOF MSE fit。内部OOFのfit指標は重みの独立検証ではない |
| 固定元3比率 | 元3の内部重みをclean OOFで決め、追加時は元3ブロック全体の配分を変更する設計。推論時の重み固定とは別の制約 |
| q100/g100 | 以後の全評価chunkが陽性となる最小実測熱流束/日別ONBからの差。有限標本の到達段階であり、秒の時間遅延・将来100%保証ではない |
| 説明性/XAI | モデルの予測根拠を可視化・定量化する手法。図の生成だけでは妥当性は確定しない |

## 研究上の主張を支える確認

回帰にはR²・RMSE・MAE、ONB条件の1秒chunk判定には近傍誤差・Recall・誤警報を用いる。連続スコアROC-AUCと、予測を二値化した互換AUCは分ける。PCA空間TreeSHAPと物理帯域マスクも別の説明対象として扱う。

未知日・独立ノイズの一般化、IGの信頼性、同期時刻に基づく早期検知は、それぞれ必要な証拠を揃えてから主張する。現在の完了/未完了は[現在地](research_status.md)を正とし、過去の成績は[日付付き記録](../experiments/README.md)へ戻って確認する。
