# 2026-05-22 発表後の研究計画整理

## 目的の再定義

今回の発表では、「ONB近傍の沸騰音特徴を物理的に妥当な根拠として使えているモデル・入力表現を明らかにすること」を研究の芯として説明した。一方で、研究タイトルに「アンサンブル学習」が入っている場合、この説明だけでは「アンサンブル学習は研究の中心から外すのか」と受け取られる可能性がある。

現時点では、アンサンブル学習は外さない。位置づけは次のように整理する。

- 研究の最終的な目的は、音響データから熱流束を回帰し、沸騰開始点近傍を早期かつ頑健に検知することである。
- そのための中心手段として、単体モデルの比較だけでなく、複数モデルの予測を統合するアンサンブル学習を用いる。
- ただし、アンサンブルで精度が上がったかだけでは不十分であり、ONB近傍の時間・周波数特徴を根拠にしているかを説明性評価とマスク実験で確認する。

したがって、研究の表現は次の形が自然である。

> 音響スペクトログラムから熱流束を回帰し、沸騰開始点近傍を検知するために、入力表現・単体モデル・アンサンブル統合を比較し、精度・頑健性・物理的妥当性の観点から有効な構成を明らかにする。

## アンサンブル学習の研究上の役割

アンサンブルは「目的」そのものではなく、目的を達成するための主要な検証対象である。特に、次の問いに答えるために使う。

1. 単体モデルよりも熱流束回帰の誤差を下げられるか。
2. 単体モデルよりもONB近傍の検知遅れや見逃しを減らせるか。
3. ノイズ条件や入力表現が変わっても性能が安定するか。
4. アンサンブルで性能が上がる場合、その改善は物理的に妥当な特徴に基づいているか。
5. 逆に、アンサンブルで精度だけ上がっても、根拠がノイズやデータセット固有の癖に寄っていないか。

先生に説明する場合は、次の返答が分かりやすい。

> アンサンブル学習は行います。今回強調した「ONB近傍の物理的に妥当な特徴を見る」という点は、アンサンブルを外すという意味ではなく、アンサンブル結果を信頼できる検知手法として評価するための軸です。単体モデルとアンサンブルを比較し、精度・頑健性・説明性の3点から、ONB近傍検知に有効な構成を明らかにしたいと考えています。

## 検証の優先順位

### P0: 研究目的と評価指標を固定する

最初に、研究目的を「アンサンブルで高精度化する研究」だけにせず、「アンサンブルを用いてONB近傍検知の精度・頑健性・根拠妥当性を検証する研究」と明文化する。

固定したい評価軸は次の通り。

- 回帰性能: R2, RMSE, MAE
- 閾値検知性能: Accuracy, Precision, Recall, F1, AUC
- ONB近傍性能: 閾値近傍のRMSE/MAE、検知遅れ、低FPR時のTPR、見逃し率
- 頑健性: SNR別性能、水流音ノイズ条件別性能、入力表現変更時の性能
- 物理的妥当性: Grad-CAM, RISE, Integrated Gradients, Attention Rollout, 時間・周波数マスク時の予測変化

### P1: 現在の中心コードの評価条件を整理する

`code/3.run_ensemble_ROC_100%_analysis.py` は研究の中心スクリプトだが、結果解釈の前に次を整理した方がよい。

- `alexnet_pred` にRandomForestの予測が入っている箇所があり、図や結果名とモデル実体がずれる可能性がある。
- 現在のAUC計算は二値化後の予測を使っているため、通常のROC/AUCとしての解釈には注意が必要である。予測熱流束の連続値をスコアとしてAUCを計算する版も併記した方がよい。
- 重み付き平均アンサンブルの重みを同じ検証foldの誤差から決めると、評価が楽観的になる可能性がある。重み決定用の内部検証、学習fold内CV、または固定ルールでの比較が必要である。
- まずは単純平均、重み付き平均、最小値選択の3方式を同じ指標で比較し、研究目的に対して意味のある方式を残す。

### P2: 現在データで基準結果を作る

最初の実験は条件を増やしすぎず、現在の中心条件で基準結果を作る。

- データ: `Pool_boiling/Subcooling_20_degrees/0.3/2025.07.09_0.3_1`
- 入力: STFT系 `.npy`, chunk 1s, maxfreq 22kHz
- ノイズ: まず no_noise と waterflow の代表条件
- モデル: RandomForest, CNN+Transformer v1, CNN+Transformer v2
- アンサンブル: 単純平均、重み付き平均
- 出力: 回帰指標、閾値検知指標、ONB近傍指標を `experiments/` にまとめる

### P3: アンサンブルの有効性を検証する

ここで初めて、タイトルに含まれるアンサンブル学習の主張を明確にする。

- 単体最良モデルとアンサンブルを比較する。
- 平均性能だけでなく、fold間のばらつき、SNR間のばらつき、ONB近傍の見逃しを比較する。
- アンサンブルが単体モデルより良い場合、どのモデルの誤差を補っているのかを確認する。
- アンサンブルが良くない場合も、単体モデルの方がONB近傍の局所特徴を捉えやすい可能性として考察できる。

### P4: 物理的妥当性を確認する

説明性評価は、可視化を出すだけでなく、予測への影響まで確認する。

- CNN系: Grad-CAM
- Transformer/Conformer系: Attention Rollout, Integrated Gradients
- モデル非依存: RISE、時間マスク、周波数マスク
- 検証: 注目領域を消すと予測熱流束や沸騰判定が変わるか
- sanity check: ラベルシャッフルや重み初期化時に、不自然に同じ可視化にならないか

### P5: 入力表現とノイズ条件を広げる

基準結果と説明性の枠組みが固まってから、入力表現を増やす。

- STFT窓幅変更: 短時間イベントと周波数分解能の違いを見る。
- CWT: 非定常な気泡音イベントの表現力を見る。
- maxfreq変更: どの周波数帯が検知に効いているかを見る。
- SNR変更: 強ノイズ下での頑健性を見る。
