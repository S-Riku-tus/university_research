# 2026-05-22 発表後の研究計画整理

## 目的の再定義

今回の発表では、「ONB近傍の沸騰音特徴を物理的に妥当な根拠として使えているモデル・入力表現を明らかにすること」を研究の芯として説明した。一方で、研究タイトルに「アンサンブル学習」が入っている場合、この説明だけでは「アンサンブル学習は研究の中心から外すのか」と受け取られる可能性がある。

現時点では、アンサンブル学習は外さない。ただし、アンサンブルを「沸騰開始点を直接検知するロジック」として置くのではなく、「ノイズや条件変動に対して検知結果を安定させるための方法」として位置づける方が自然である。

- 研究の主系列は、音響スペクトログラムから熱流束を回帰し、予測熱流束を閾値処理することでONB近傍を検知することである。
- アンサンブルは、その主系列を支える頑健化手法として扱う。特に、深層学習モデルと従来型機械学習モデルなど、見ている特徴や誤差の出方が異なるモデルを組み合わせることで、単体モデルに依存した不安定性を下げられるかを検証する。
- したがって、アンサンブルの評価では「平均精度が上がったか」だけでなく、「ノイズ条件下で見逃しが減るか」「foldや条件間のばらつきが小さくなるか」「改善が物理的に妥当な時間・周波数特徴に基づくか」を確認する必要がある。

したがって、研究の表現は次の形が自然である。

> 音響スペクトログラムから熱流束を回帰し、予測熱流束の閾値処理によって沸騰開始点近傍を検知する。その際、入力表現と単体モデルに加えて、複数モデルの予測を統合するアンサンブル学習をノイズ・条件変動に対する頑健化の方法として比較し、精度・頑健性・物理的妥当性の観点から有効な構成と限界を明らかにする。

より短く発表用に言う場合は、次の表現でもよい。

> 音響スペクトログラムに基づく熱流束回帰と閾値検知を基本として、異なる特徴を捉える複数モデルのアンサンブルにより、ノイズ下でも安定してONB近傍を検知できる構成を明らかにする。

## 研究計画の骨組みへの対応

`研究進捗報告/研究計画の基本となる考え方.docx` の流れに合わせると、本研究は次のように整理できる。

ここでは、いきなり研究目的を書くのではなく、次の順番で考えると論理が通りやすい。

1. 背景とニーズ: なぜ沸騰・異常兆候を早期に把握したいのか。
2. 技術的課題: そのニーズに対して、既存の方法や単純な解析では何が難しいのか。
3. 研究目的: その課題を解くために、本研究で何を明らかにするのか。
4. 着眼点・着想: 目的を達成するために、どの現象・表現・モデル構成に注目するのか。
5. 研究目標: 目的を検証可能なタスクに分け、何を達成すれば目的に答えたことになるのか。

### 1. ニーズ

高速炉などの冷却系では、冷却状態の変化や沸騰に関わる異常兆候を、できるだけ早く、かつ運転系に大きく干渉しない形で把握する必要がある。本研究のニーズは、大きな原子力システム上のニーズと、現在扱っているプール沸騰音データに即したニーズに分けて整理できる。

- 高速炉などの熱流動系では、冷却材の状態変化を早期に把握することが、安全性評価や異常検知の観点で重要である。
- 沸騰開始や気泡発生は、熱伝達状態の変化に関わる現象であり、異常兆候や運転状態の変化を捉える手がかりになり得る。
- 実機・模擬体系の監視では、温度や圧力などの従来計測だけでなく、非接触または外部取り付け可能な音響計測を使えれば、追加的な診断情報を得られる可能性がある。
- 音響データは時間分解能が高く、気泡発生や流動変化に伴う短時間のイベントを捉えられる可能性がある。
- 一方で、現実の計測環境では流動音、水流音、ポンプ音、構造振動、反射音などが混在するため、清浄な実験データだけで成立する検知では不十分である。
- そのため、本研究では「沸騰の有無を当てる」だけでなく、「ノイズが重なる条件でも、沸騰開始点近傍を安定して検知できるか」を重要なニーズとして扱う。
- また、安全監視や物理現象の理解に使うためには、モデルが何を根拠に判断したのかを説明できる必要がある。単なるブラックボックスの高精度化だけでは、研究としても実用上も説得力が弱い。
- 過去の事故・異常事例との関係は、今後文献で具体例を整理する必要がある。ただし一般的には、冷却機能低下や熱流動状態の変化を早期に検知する技術は、予兆監視・異常診断の観点から重要なニーズになる。

### 2. 課題

上のニーズに対して、本研究で解くべき課題は「音から熱流束やONB近傍を推定できるか」だけではない。特に、ONB近傍の信号の弱さ、ノイズの混入、モデルごとの見ている特徴の違い、説明性の不足が課題になる。

- ONB近傍では、気泡発生が始まる前後の変化が微小で、沸騰が十分発達した状態に比べると音響的な差が小さい可能性がある。
- 気泡発生に伴う音は、時間的に離散的・非定常に現れる可能性があり、単純な平均音圧や単一周波数の閾値だけでは捉えにくい。
- 水流音や装置由来のノイズは、沸騰音と周波数帯や時間構造が重なる可能性があり、スペクトログラム上でも単純に分離できるとは限らない。
- 熱流束回帰では、予測値のわずかな誤差が閾値付近で検知結果を反転させるため、ONB近傍では通常のRMSEやR2だけでは評価が不十分である。
- CNN、CNN+Transformer、RandomForestなどのモデルは、それぞれ異なる特徴を見ている可能性がある。CNNは局所的な時間・周波数パターン、Transformer系は時間方向の関係、RandomForest系は圧縮特徴量に基づく大まかな分離に強みを持つ可能性がある。
- 単体モデルだけに依存すると、特定のノイズ条件やデータセット固有の癖に適合してしまい、条件が変わったときに性能が落ちる可能性がある。
- アンサンブルはこの不安定性を下げる候補だが、単に平均を取れば必ず良くなるわけではない。誤ったモデルを混ぜると、ONB近傍の感度が下がる可能性もある。
- Attention mapなどの可視化だけでは、モデルが本当に物理的に意味のある特徴を使っているとは言い切れない。マスク実験やsanity checkと合わせて、予測への影響を確認する必要がある。

### 3. 研究目的

上記のニーズと課題を踏まえると、本研究目的は次のように置ける。

> プール沸騰音に含まれるONB近傍の微弱な時間・周波数特徴を、ノイズ下でも熱流束推定と沸騰開始点近傍の検知に利用できるかを明らかにする。そのために、音響スペクトログラムから熱流束を回帰し、予測熱流束の閾値処理によりONB近傍を検知する流れを用いる。さらに、入力表現、単体モデル、異種モデルを含むアンサンブル統合を比較し、どの構成が安定した検知につながるか、またその判断根拠が物理的に妥当かを評価する。

この目的の中で、アンサンブルは「検知ロジックそのもの」ではなく、「ノイズや条件変動に対して、熱流束回帰と閾値検知を安定化できるかを検証する方法」として扱う。

つまり、手法を構築すること自体が目的ではなく、音響データを用いたONB近傍検知の成立条件、有効なモデル構成、ノイズ下での限界を明らかにすることが目的である。

研究目的をさらに分解すると、次の3つになる。

- 精度: 音響スペクトログラムから熱流束をどの程度正確に回帰できるか。
- 頑健性: ノイズ条件やデータ条件が変わったときに、ONB近傍の見逃しや誤検知をどの程度抑えられるか。
- 物理的妥当性: モデルやアンサンブルが、沸騰現象に関係する時間・周波数特徴を根拠にしていると説明できるか。

### 4. 着眼点・着想

課題解決を図るうえでの着眼点は、「音響スペクトログラム」「熱流束回帰」「閾値検知」「異種モデルのアンサンブル」「説明性評価」を一つの流れとして接続することである。

- ONB近傍では、気泡発生や離脱に伴う短時間・局所的な音響イベントが発生し、その痕跡がスペクトログラム上の時間・周波数パターンとして現れる可能性がある。
- 直接の二値分類ではなく熱流束回帰を行うことで、沸騰状態を連続的な物理量の推定として扱い、その後に閾値処理でONB近傍を検知できる。
- STFT、CWT、窓幅変更、maxfreq変更などの入力表現を比較することで、短時間イベントと周波数分解能のどちらがONB近傍検知に効いているかを調べられる。
- CNN系、CNN+Transformer系、RandomForest系は、同じスペクトログラムから異なる特徴を拾う可能性がある。これらを比較することで、どのモデル構造がどの特徴に強いかを見られる。
- 異なるモデルを組み合わせるアンサンブルにより、特定モデルがノイズや局所的な癖に引っ張られる影響を下げ、予測熱流束と閾値検知を安定化できる可能性がある。
- アンサンブルの有効性は、単体最良モデルとの比較、fold間ばらつき、SNR別性能、水流音ノイズ条件別性能、ONB近傍の見逃し率で評価する。
- Grad-CAM、RISE、Integrated Gradients、Attention Rollout、時間・周波数マスクを用いて、モデルが見ている領域と予測値の変化を確認する。
- もしアンサンブルで精度が上がっても、根拠がノイズ帯域やデータセット固有の癖に寄っていれば、本研究の目的に対しては不十分である。逆に、精度改善が小さくても、どの条件で単体モデルが有利かを明らかにできれば研究上の知見になる。

### 5. 研究目標

研究目的を達成するための目標は、次のように段階的に置く。

- 目標1: 音響データからスペクトログラムまたは `.npy` 特徴量を作成し、熱流束ラベルと対応づけるデータ処理を整理する。
- 目標2: STFTの窓幅、周波数上限、CWTなどの入力表現を比較し、ONB近傍の特徴を捉えやすい表現を検討する。
- 目標3: RandomForest、CNN系、CNN+Transformer系などの単体モデルを同一条件で比較し、回帰性能と閾値検知性能の基準結果を作る。
- 目標4: 単純平均、重み付き平均、必要に応じてstackingなどのアンサンブル統合を比較し、単体最良モデルに対する改善の有無を調べる。
- 目標5: no_noise、水流音ノイズ、SNR変更などの条件で性能を比較し、アンサンブルがノイズ下の見逃し、誤検知、fold間ばらつきを減らすかを検証する。
- 目標6: 通常の回帰指標だけでなく、ONB近傍RMSE/MAE、検知遅れ、低FPR時のTPR、見逃し率など、研究目的に合った評価指標を整理する。
- 目標7: 説明性評価とマスク実験により、モデルやアンサンブルの判断根拠が沸騰現象に関係する時間・周波数特徴と対応しているかを確認する。
- 目標8: 最終的に、どの入力表現、単体モデル、アンサンブル構成がどのノイズ条件で有効か、また限界はどこにあるかを研究計画・修士論文の主張として整理する。

### 6. 研究仮説

研究計画としては、次の仮説を置いて検証すると筋が通りやすい。

- 仮説1: ONB近傍では、気泡発生に伴う非定常な音響イベントが時間・周波数表現に現れ、熱流束回帰と閾値処理により検知できる。
- 仮説2: 異なる特徴を捉える複数モデルを組み合わせることで、単体モデルよりもノイズ条件下での熱流束回帰とONB近傍検知が安定する。
- 仮説3: アンサンブルが有効な場合、その改善は単なる平均化による偶然ではなく、モデル間の誤差の補完や特徴の多様性によって説明できる。
- 仮説4: 物理的に妥当なモデルでは、重要領域の可視化やマスク実験において、ONB近傍の気泡音に関係する時間・周波数領域が予測に影響する。

## アンサンブル学習の研究上の役割

アンサンブルは「目的」そのものではなく、目的を達成するための主要な検証対象である。特に、ノイズに対する頑健化とモデル依存性の低減という観点で位置づける。

本研究での検知ロジックは、基本的には次の流れである。

1. 音響データをスペクトログラムなどの時間・周波数表現に変換する。
2. 各モデルが熱流束を回帰する。
3. 必要に応じて複数モデルの予測熱流束をアンサンブル統合する。
4. 統合後の予測熱流束を閾値処理し、ONB近傍を検知する。

この流れでは、アンサンブルは3番目の「予測熱流束を安定化する処理」であり、ONB検知そのものは4番目の閾値処理で行う。したがって、アンサンブルの研究上の問いは次のようになる。

1. 単体モデルよりも熱流束回帰の誤差を下げられるか。
2. 特にノイズ条件下で、単体モデルよりもONB近傍の検知遅れや見逃しを減らせるか。
3. fold間、SNR間、入力表現間で性能のばらつきを小さくできるか。
4. CNN、CNN+Transformer、RandomForestなど、異なる性質のモデルを組み合わせることに意味があるか。
5. アンサンブルで性能が上がる場合、その改善はどの単体モデルの弱点を補った結果なのか。
6. アンサンブルで精度だけ上がっても、根拠がノイズやデータセット固有の癖に寄っていないか。
7. アンサンブルが有効でない条件がある場合、その理由はモデル間の誤差相関、重み決定方法、ONB近傍感度の低下などで説明できるか。

先生に説明する場合は、次の返答が分かりやすい。

> アンサンブル学習は行います。ただし、アンサンブルを沸騰開始点の検知ロジックそのものとして置くのではなく、音響スペクトログラムから回帰した熱流束をノイズ下でも安定させるための方法として位置づけています。深層学習モデルと従来型機械学習モデルなど、異なる特徴を捉えるモデルを組み合わせることで、単体モデルに依存した不安定性を下げられるかを検証します。そのうえで、予測熱流束の閾値処理によるONB近傍検知について、精度・頑健性・物理的妥当性の3点から有効な構成を明らかにしたいと考えています。

## 検証の優先順位

### P0: 研究目的と評価指標を固定する

最初に、研究目的を「アンサンブルで高精度化する研究」だけにせず、「熱流束回帰と閾値検知を基本とし、アンサンブルがノイズ下の精度・頑健性・根拠妥当性を高めるかを検証する研究」と明文化する。

固定したい評価軸は次の通り。

- 回帰性能: R2, RMSE, MAE
- 閾値検知性能: Accuracy, Precision, Recall, F1, AUC
- ONB近傍性能: 閾値近傍のRMSE/MAE、検知遅れ、低FPR時のTPR、見逃し率
- 頑健性: SNR別性能、水流音ノイズ条件別性能、入力表現変更時の性能
- 物理的妥当性: Grad-CAM, RISE, Integrated Gradients, Attention Rollout, 時間・周波数マスク時の予測変化

### P1: 現在の中心コードの評価条件を整理する

`code/3.run_ensemble_ROC_100%_analysis.py` は研究の中心スクリプトだが、結果解釈の前に次を整理した方がよい。

- `alexnet_pred` にRandomForestの予測が入っている箇所があり、図や結果名とモデル実体がずれる可能性がある。
- 現在のAUC計算は二値化後の予測を使っているため、通常のROC/AUCとしての解釈には注意が必要である。予測熱流束の連続値をスコアとしてAUCを計算する版も併記した方がよい。
- 重み付き平均アンサンブルの重みを同じ検証foldの誤差から決めると、評価が楽観的になる可能性がある。重み決定用の内部検証、学習fold内CV、または固定ルールでの比較が必要である。
- まずは単純平均、重み付き平均、最小値選択の3方式を同じ指標で比較し、研究目的に対して意味のある方式を残す。

### P2: 現在データで基準結果を作る

最初の実験は条件を増やしすぎず、現在の中心条件で基準結果を作る。

- データ: `Pool_boiling/Subcooling_20_degrees/0.3/2025.07.09_0.3_1`
- 入力: STFT系 `.npy`, chunk 1s, maxfreq 22kHz
- ノイズ: まず no_noise と waterflow の代表条件
- モデル: RandomForest, CNN+Transformer v1, CNN+Transformer v2
- アンサンブル: 単純平均、重み付き平均
- 出力: 回帰指標、閾値検知指標、ONB近傍指標を `experiments/` にまとめる

### P3: アンサンブルの有効性を検証する

ここで初めて、タイトルに含まれるアンサンブル学習の主張を、ノイズ下の頑健化という観点から明確にする。

- 単体最良モデルとアンサンブルを比較する。
- 平均性能だけでなく、fold間のばらつき、SNR間のばらつき、ONB近傍の見逃しを比較する。
- アンサンブルが単体モデルより良い場合、どのモデルの誤差を補っているのかを確認する。
- アンサンブルが良くない場合も、単体モデルの方がONB近傍の局所特徴を捉えやすい可能性として考察できる。

### P4: 物理的妥当性を確認する

説明性評価は、可視化を出すだけでなく、予測への影響まで確認する。

- CNN系: Grad-CAM
- Transformer/Conformer系: Attention Rollout, Integrated Gradients
- モデル非依存: RISE、時間マスク、周波数マスク
- 検証: 注目領域を消すと予測熱流束や沸騰判定が変わるか
- sanity check: ラベルシャッフルや重み初期化時に、不自然に同じ可視化にならないか

### P5: 入力表現とノイズ条件を広げる

基準結果と説明性の枠組みが固まってから、入力表現を増やす。

- STFT窓幅変更: 短時間イベントと周波数分解能の違いを見る。
- CWT: 非定常な気泡音イベントの表現力を見る。
- maxfreq変更: どの周波数帯が検知に効いているかを見る。
- SNR変更: 強ノイズ下での頑健性を見る。

- `docs/progress_index.md`: 2026-05-22発表後の先生コメントと対応方針を追記する。
- `docs/model_notes.md`: 現在の中心スクリプトにおけるモデル名、AUC計算、重み付き平均の注意点を追記する。
- `configs/experiments/`: 次に回す条件をyamlで残す。
- `experiments/`: 実験を実行したら、数値と考察をrun summaryとして残す。

コード変更は、研究目的が固まってから次の順で進める。

1. モデル名と変数名を実体に合わせる。
2. AUC計算で連続値スコア版を追加する。
3. アンサンブル重みの決定方法を評価foldから切り離す。
4. ONB近傍指標と検知遅れ指標を追加する。
5. 説明性・マスク実験を別スクリプトまたは共通関数として追加する。
