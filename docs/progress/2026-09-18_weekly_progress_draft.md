# 植木研・研究進捗報告（発表前の下書き）

日付：2026年9月18日（9月15日時点の結果から作成）  
名前：柴崎陸

## 【S】Subjective

音響から熱流束を推定してONB近傍を捉えるため、予測精度に加えて、各モデルがどの時間・周波数特徴を利用しているかを確認したい。今週は実験日と周波数上限を固定し、ノイズ条件による精度と説明性の違い、出力をどこまで信頼できるかを整理した。

## 【O】Objective

2025年6月11日の18録音について、周波数上限22 kHz、無雑音とreference SNR 0〜−20 dBの7条件で、RF・CNN＋Transformer・AlexNetおよび2統合方式を評価した。元WAVを分離した3-foldで、条件ごとに同じノイズを学習・評価に用いた。深層モデルは300 epochs、batch size 16の完了記録を確認した。

主評価は元WAV内の予測中央値とした。CNN＋Transformerは5/7条件で単体最高R²となり、無雑音では0.9623だった。単純平均は4/7条件で最良単体を上回り、−8 dBではRFの0.9227から0.9337へ改善した。他の改善条件の差は0.001未満だった。

共通帯域マスクではRFの2–5 kHzが全21組のfold×条件で最大のR²低下を示した。CNN＋Transformerでは2–5 kHzと15–22 kHzなどに分かれ、AlexNetでは1–2 kHzが15/21組で最大となった。

TreeSHAPは105例で再構成の絶対誤差中央値0.262 W/m²だった。一方、IGは210例すべてでcompleteness相対誤差が説明用の目安0.05を超えた。入力小摂動への説明画像の相関中央値は約0.9999、最終層ランダム化後は約0.63〜0.64だった。

ONB評価では全35組でWAV ROC-AUCが1.0となったが、32組は最初のONB WAVを見逃した。近傍±10%に含まれる録音は1本だった。新しい実験・同時計測は今回行っていない。

## 【A】Assessment

今回の範囲ではCNN＋Transformerが多くの条件で高精度だったが、最良の方式はノイズ条件で変わった。統合による補完は認められる条件があるものの、常に最良単体を上回るとは言えない。単一実験日・seedで各ノイズに合わせて再学習した結果であり、未知ノイズ・別日への一般化は今後確認する。

RFの帯域マスク結果は一貫している。深層モデルは異なる特徴依存を示す一方、AlexNetはゼロ置換で予測が大幅に崩れるため、マスクの応答量をそのまま物理的重要度と解釈することは難しい。

IG画像には入力の低周波構造と対応して見える部分があるが、数値整合性が不足している。生power上のゼロbaselineからの積分とlog変換の組合せが原因候補と考えられ、log変換だけの補助数値例でも64分割の誤差を確認した。学習済みモデル全体の原因は未確定である。局所的に安定した画像が得られることと、予測差を正しく説明できることを分けて扱う。

ROC-AUCが高くても固定閾値でONB点を捉えられないため、全域回帰とONB捕捉は別の課題として評価する必要がある。現状は測定点順の比較であり、秒単位の早期検知は評価できていない。

## 【P】Plan

1. 今回の発表では、性能・共通マスク・対応を確認した代表画像・信頼性診断を示し、物理的に解釈できる範囲を整理する。
2. 発表後、ONB前後の測定点追加、独立反復、同時計測の正解源と同期方法を検討する。
3. 説明性は少数例からIGの積分経路・点数・baseline、マスクの置換値を確認する。必要なモデル保存・限定再学習の範囲を決める。
4. 進行中の3 kHzが揃えば別解析として比較する。一般化評価は代表条件でclean_only、次いで別日評価を進める。

## 相談したいこと

- 今回は共通帯域マスクと信頼性診断を説明性の主材料に置き、IGを検証途中として報告する方針でよいか。
- ONB近傍の点数不足に対し、細かい熱流束刻み・同条件反復・別日のどれを先に確保するか。
- 同時計測では、どの観測からONBの正解時刻を決め、音声とどう同期するか。
