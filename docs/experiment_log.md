# 実験・解析ログ

実験や機械学習の試行を、後から比較できる形で記録するためのファイルです。詳細な結果ファイルや図は各結果ディレクトリに残し、ここには要点を記録します。

## 記録テンプレート

```text
## YYYY-MM-DD 実験名

- 目的:
- 使用データ:
- 前処理:
- 入力表現:
- モデル:
- 学習条件:
- 評価指標:
- 主な結果:
- 解釈:
- 次に試すこと:
- 関連ファイル:
```

## 評価指標メモ

- `R2`: 熱流束回帰の当てはまり。全体だけでなく、閾値以上の高熱流束領域でも見る。
- `AUC`: 閾値による沸騰/非沸騰判定の性能。ただし、連続スコアではなく二値予測から計算している場合は解釈に注意する。
- `RMSE`: 予測誤差の大きさ。大きな外れ値に敏感。
- `MAE`: 平均的な予測誤差。RMSEより外れ値の影響が小さい。
- `100%分類閾値`: ある熱流束以上で全サンプルが沸騰側に分類されるかを見るための指標。
