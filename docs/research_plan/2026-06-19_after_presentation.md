# 2026-06-19 発表後の研究方針

作成日: 2026-06-19  
参照: `研究進捗報告/2026/619（研究計画発表）/スライド内容案_0619.md`

## 位置づけ

6月19日の研究計画発表では、RandomForest、CNN+Transformer、AlexNet、Ensembleの42条件結果を報告した。その結果、現時点ではRandomForestが最も安定して高性能だった。

ただし、発表後のコメントとその後の方針整理を踏まえると、今後はRandomForestだけを基準に固定するのではなく、**CNN+Transformer、AlexNet、RandomForestの各モデルについて、学習設定・評価・説明性を整えたうえで比較する** 必要がある。特に、CNN系は入力正規化、log変換、学習率、early stoppingなどの調整不足で性能が低く見えている可能性がある。

## 教授コメントから見えた論点

1. 平均R2などの「平均」が何を平均しているのかを明確にする。
2. no_noiseよりノイズあり条件の性能が高い点は違和感があり、PCAやノイズ付与方法の影響を確認する。
3. PCAを挟むと、説明性評価で元の時間・周波数位置に戻す解釈が難しくなる。
4. アンサンブルは最後の上積みでよく、提案手法の核心は早期検知性能に置く。
5. 分類ではなく回帰タスクが主戦場なので、各モデルの回帰出力に対する説明性を確認する。
6. 周波数帯域方向に切ったとき、それぞれの帯域が熱流束予測にどう寄与しているかを、モデル間で比較できる形にする。

## 改訂後の研究主軸

本研究の主軸は、音響スペクトログラムから熱流束を回帰し、その回帰結果を用いてONB近傍を早期に検知することである。

今後は、どれか1つを主軸に固定せず、以下をモデル横断で確認する。

- 各モデルの回帰性能が、適切なチューニング後にどの条件で成り立つか。
- ONB近傍での誤差や見逃しが小さいか。
- ノイズ条件を変えても本当に頑健か。
- 各モデルで、どの周波数帯・時間帯が熱流束予測に寄与しているか。
- RandomForestでは、PCAに依存せず物理的に説明できる特徴で同等の性能が出るか。

アンサンブルは、各モデル単体の性能と説明性を整理した後に、性能や安定性の上積みとして扱う。

## 直近の優先順位

### 1. 結果の集計定義

- 1条件内の5-fold結果をどう集計しているかを明記する。
- 条件間平均、周波数別平均、ノイズ別平均を分けて保存する。
- 平均だけでなく、中央値、ばらつき、外れ条件も見る。

### 2. 回帰結果の細部確認

- 代表条件の予測-実測散布図を確認する。
- 残差プロットを作る。
- 熱流束帯別誤差を確認する。
- ONB近傍の誤差と見逃しを重点的に見る。

### 3. CNN+Transformer / AlexNetのチューニング

- 入力のlog変換・標準化の有無を比較する。
- 学習率、optimizer、batch sizeを見直す。
- early stoppingの監視指標をvalidation loss中心にする。
- AlexNetのDense層やdropoutを見直す。
- CNN+Transformerの時間方向分割が意図通りに働いているか確認する。

### 4. ノイズ条件の異常の切り分け

- PCAあり/なしでノイズ別性能を比較する。
- ノイズ付与処理が熱流束ラベルと相関していないか確認する。
- no_noiseだけサンプル数、前処理、保存経路が異ならないか確認する。

### 5. PCAの妥当性確認

- 累積説明分散を見る。
- 上位主成分が何を表すか確認する。
- PCA特徴が全体エネルギーに偏っていないか確認する。

### 6. モデルごとの説明性評価

- RandomForest: TreeSHAP、permutation importance、周波数帯・時間帯マスク。
- AlexNet: Grad-CAM、Integrated Gradients、入力マスク。
- CNN+Transformer: Attention、Integrated Gradients、時間パッチマスク、周波数帯マスク。
- 可能であれば、周波数帯 x 時間窓の平均エネルギー特徴を作り、RFのPCA版と比較する。

### 7. 早期検知性能の定義

- ONB近傍Recall
- ONB近傍False Negative
- ONBしきい値付近の熱流束誤差
- 100%分類可能な熱流束下限
- 可能であれば検知リードタイム

## 今後の研究計画での位置づけ

6月下旬から7月は、評価集計の定義を明確化し、CNN+TransformerとAlexNetのチューニングを進める期間にする。  
7月から8月にかけて、3モデルそれぞれの回帰結果とONB近傍性能を比較し、RFについてはPCAの妥当性も確認する。  
8月から10月にかけて、各モデルの説明性評価を進め、周波数帯・時間帯の寄与を比較する。  
10月以降に、早期検知性能と一般化性能を整理する。  
アンサンブルは、各モデル単体の性能と説明性が整理できた後に比較・上積みとして扱う。

## 次に先生へ確認すること

1. どれか1つのモデルを主軸に固定せず、3モデルそれぞれをチューニング・説明性評価まで行ってから比較する方針でよいか。
2. 早期検知性能は、どの指標を中心に定義すべきか。
3. ノイズあり条件で高性能な結果は、原因が分かるまで確定的に主張しない方がよいか。
4. RandomForestではPCA特徴だけでなく、解釈可能な周波数帯 x 時間窓特徴も比較する方針でよいか。
