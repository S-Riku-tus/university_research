## 1. 優先する結論と、その根拠

**直近は、統合の成功・失敗を既存予測から説明し、選別と学習の安定性を確認する。その結果で必要性を判断して、固定モデルの雑音試験、帯域の追加検証、統合方式の変更へ進む。**

全域回帰の改善とONB近傍での非改善が共存するため、「回帰が良くなったのでONB検知にも有効」とまとめることはできない。説明性の図の違いを理由に新しいモデルを加える前に、実際にどの誤りを直す必要があるかを決める。[現状の根拠](../../experiments/2026-09-18_onb_full_sweep_151715/README.md)。

## 2. まず作る成果物：目的と問題を一枚に対応付ける

最初の作業は、22 kHz・無雑音の改善条件と−8 dBの不改善条件を代表候補として、下表の判断用記録を作ること。これは既知の成績を使った原因診断であり、独立な最終検証ではない。

| 記録項目 | 必要な内容 |
|---|---|
| 問い | 全域の改善がどの熱流束領域で生じ、なぜONB近傍に引き継がれないか |
| 比較単位 | 同じ1秒chunkの単体・統合予測を対応付ける。WAV別表示は原因診断の整理であり、通常評価をWAV中央値へ戻す変更ではない |
| 保存値 | 各単体と統合の符号付き残差、重み、二乗誤差、ONB見逃し・誤警報の訂正／追加数 |
| 領域 | ONB前・近傍・ONB以上。近傍の定義と対象WAV・秒数を固定し、60秒を独立60実験と数えない |
| 対照 | 現行重み、等重み、各単体。同一予測で比較し、テストに最適な重みをfitしない |
| 終了条件 | 改善／悪化を担う標本群、説明できる範囲、未識別の原因、必要なら次の1比較が記載できる |

固定重みで総和が1なら、単体残差をe_m、重みをw_mとして、各標本の統合二乗誤差は **(Σw_m e_m)² = Σw_m²e_m² + 2Σ_{m<n}w_mw_n e_m e_n**。交差項まで見ることで、異符号の誤差の相殺と同方向の誤差の共有を区別できる。残差相関だけでは平均バイアスの影響を落とすため、この分解や符号付き残差を併用する。これは数学的な分解で、周波数特徴が原因だと証明するものではない。

## 3. 段階ごとの着手条件・比較・終了条件

| 段階・概略時期 | 行う比較／確認 | 完了とする条件 | 次へ進む判断 |
|---|---|---|---|
| A：9月後半〜10月初め | 上記の既存予測診断、学習曲線と実行条件・乱数の照合 | 統合失敗の所在と、学習不足・過学習・日差・重みの偏りのうち未識別な候補を整理 | モデル学習が不安定なら基準条件の検証を先行。単にepochを増やす判断にはしない |
| B：9月後半〜10月 | 22 kHz・無雑音・200 epochs・6/11学習→6/18全1080秒を基準候補に選別なし／ありの対応比較 | 同じ分割・seed群で性能差、除外数、学習更新回数、ONB近傍の利害を提示 | まず3 seedsを提案。探索的な安定性確認であり有意性の保証ではない。効果の符号が揺れるなら優位を未確定とする |
| C：10月 | clean_only：モデル・PCA・scaler・重みを固定し、無雑音と事前指定の代表SNRで比較 | 無雑音からの劣化量と雑音時の絶対性能、ONB誤りを単体と統合で示す | 既存matchedと区別。代表条件で未識別な点がある場合のみ帯域・SNRを拡張 |
| D：9月後半〜11月、必要時 | 等重みと現行重みを基準に、診断で必要になった統合方式のみ比較 | 追加方式の採用・不採用理由、単体比較、失敗条件を記録 | 重みの偏りが問題なら安定化、共通誤差が問題なら入力・学習側の検証を優先 |
| E：9月〜11月 | 成功／失敗標本を揃え、マスク・収束確認済みIGと残差を対応。必要帯域だけ対照摂動・再学習 | 「どこに依存」「どの誤りと対応」「改良に使えるか」を根拠と限界付きで答える | 微細化しても判断が変わらない場合は終了。活用効果がなければ不採用を結論にする |
| F：準備は9〜10月、可能なら11月に検証 | 設定を固定した後の独立日。物理的検知を主張する場合は独立な正解源も設計 | 独立評価を実施、または取得不能の理由と主張を限定する範囲を明記 | データ追加を自動実施しない。計測可否と必要な根拠を早期に相談する |
| G：10月〜翌2月 | 背景・方法→結果・考察・結論→完成・発表準備 | 各主張が条件表・図・予測・限界へ辿れる原稿と発表資料 | 正式期限が判明したら逆算。1月末を既定締切としない |

Bは選別効果と反復の対応比較に絞り、7/9追加、別の学習予算、閾値探索を同時に混ぜない。現行の損失図はtraining lossのみで、validation loss・best epochは記録していない。200 epochsの妥当性に疑いが残れば、学習日の元WAV分離で内部検証曲線を取る限定runを設計し、学習側で予算を決め直して両条件へ適用する。選別で標本数・更新回数が変わるため、改善が認められた後に同数ランダム除外等で要因を識別する。

Cの代表SNRは無雑音・中程度・強い雑音等を計算前に固定する。−8 dBは既存の失敗条件として診断対象にできるが、その結果を見て選んだことを明記する。固定モデル・前処理の保存有無を確認し、未保存なら再学習が必要なことを条件書に残す。

## 4. 修論の達成条件と、手法の有効性の条件を分ける

### 研究としての最低達成条件（提案）

| 項目 | 確認できれば完了とする証拠 |
|---|---|
| 評価の妥当性 | 学習・内部検証・別日評価の分離と前処理fit範囲、ラベル・選別定義、評価標本が追跡可能 |
| 選別の判断 | 同じ評価集合で選別なし／ありを比較し、採用・不採用・未確定の理由を示せる |
| アンサンブル手法の検証 | 単体と統合の絶対性能、雑音による劣化、ONBへの影響、成立・不成立条件を同じ評価定義で説明できる |
| 要因分析 | 代表的な成功／失敗について、確認事実・原因仮説・識別比較の結果を示せる。説明性を使う範囲と使えない範囲が明確 |
| 再現性と適用範囲 | seedの変動と実験日差を区別。独立日で未確認なら、その制限を結論に残す |
| 論文・発表 | 目的→問題→手法の理由→結果→限界が一続きで、結果を希望する結論へ置き換えていない |

統合が常に最良になることや、新方式の実装自体は修論完了の条件にしない。否定的結果でも、比較が適切で成立範囲や失敗理由への回答があれば成果となる。ただし、物理的な秒単位の発泡検知まで実証したという主張には、その独立な正解が別途必要。

### 「改善した」「採用する」と言う条件（計算前に固定する案）

- 回帰改善は、学習側で選んだ比較単体に対する対応差で判定する。テスト上の最良単体も併記できるが、事後的な参照値と明記する。
- ノイズ劣化抑制は、雑音時の絶対性能と各方式自身の無雑音からの低下量を併記する。無雑音性能が低い方式の小さな低下量だけを利点としない。
- ONBへの有効性は、固定閾値の見逃し・誤警報、近傍RMSEを確認する。AUC上昇だけで検知改善とはしない。回帰だけ改善した場合はその範囲に結論を限定する。
- 採用に必要な最小改善幅と許容するONB悪化幅は、用途・計測のばらつきから決める必要があり、現資料だけで合理的な数値は確定できない。最終比較前に「RMSE差、近傍RMSE差、見逃し率差、誤警報率差、許容幅」を条件書へ記す。未設定の間は探索的比較とする。
- 1秒chunkの指標を使いつつ、不確かさを評価する場合は元WAV内の依存を保った対応比較を用いる。少数seedの反復は独立日での再現性の代わりにならない。区間推定を出すなら独立WAV数・日数の制限も明記する。

この整理は、現行コードへ新しい「主評価」切替を実装する提案ではない。通常指標を併記した上で、どの主張をどの結果で判定するかを研究計画に明示する。

## 5. 今やること・条件付きで行うこと・保留すること

**今やること**は、既存予測の成功／失敗の対応表と学習曲線の診断、選別対照の条件書、独立評価に必要なデータ・設備の可否確認。独立評価の準備だけは解析の終了を待たない。

**条件付き**は、周波数帯の細分化、背景値置換、帯域保持／除去後の再学習、epoch追加、新統合方式、7/9追加効果の比較。各作業で「どの結果なら何を採用・棄却するか」を先に書ける場合に着手する。

**保留**は、35条件の一括再実行、新モデルの網羅探索、全説明手法の追加、時間区間マスクの再導入、選別によるデータ不足への対策の自動再開。完了済みの実装や可視化を未完了として繰り返さない。

6/18は既に繰り返し参照しているため、ここで得た条件選択は開発・原因診断として扱う。新しい独立評価へ進む前に帯域、選別、モデル、重み、閾値、採否条件を固定する。独立評価を見て変更した場合は、その評価も開発に使ったことを記録する。

## 6. 次回の教授との議論に持参するもの

持参物は、修論目的との対応表、統合が改善／悪化した領域の表、学習と説明計算の信頼性の確認結果、次の一比較の条件書。相談事項は、修論で回帰とONBそれぞれに求める到達点、用途から決める許容誤り、独立日・同期正解の取得可否、正式な提出・発表日とする。

次の報告では、「何をしたか」に加えて**「この結果によって何を採用・保留と判断し、修論のどの問いへの回答が進んだか」**を必ず一文で示す。
