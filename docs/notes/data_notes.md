# データの読み方

更新日: 2026-09-15。データの版・容量・場所は[データ索引](../data_inventory.md)、生成条件は[現行データ設定](../../configs/datasets/waterflow_20260817_1s.yaml)で管理する。

## 現行経路

元WAV → 高域通過 → 固定global RMSによるノイズ付与 → 1秒STFT power → 周波数上限で切り出し → 224×224へresize → `.npy`とprovenanceを保存する。

- 06.11/06.18/07.09は2025年の収録日。解析実行日の2026年とは区別する。
- ラベルは熱流束（W/m²）。現行manifestに高精度値があり、旧CSVの丸め値だけでONB境界を決めない。
- 分割は元WAV IDを保つ。日をまたぐ場合は実験名と元WAV IDの組で識別する。
- `reference_SNR`と実現SNRを区別する。同じ元WAVのノイズ違いは独立録音ではない。
- 最大周波数を変えて毎回224画素にする比較では、周波数分解能や補間も変わる。純粋な帯域除去実験とは区別する。
- 500 Hz高域通過後の結果から、除去された低周波の有用性は判断できない。
- ONB時刻や気泡イベント正解は、熱流束ラベルや予測の閾値交差から自動的には得られない。

旧データの扱いと生成不具合の経緯は[データ索引](../data_inventory.md)と[8/17診断](../research_plan/2026-08-17_noise_accuracy_reversal_investigation.md)を参照する。
