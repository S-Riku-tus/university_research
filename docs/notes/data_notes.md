# データ整理メモ

## データの流れ

1. 実験音声を取得する。
2. ハイパスフィルタを適用する。
3. 必要に応じて水流音や白色雑音をSNR別に付与する。
4. 指定秒数のchunkに分割する。
5. STFTなどで周波数特徴を計算する。
6. 最大周波数を制限し、`224 x 224` にリサイズする。
7. `.npy` または画像として保存する。
8. ファイル名先頭の熱流束値を教師ラベルとして読み込む。

## よく出てくる条件

- `CHUNK`: 音声を何秒ごとに切るか。
- `maxfreq`: 解析に使う最大周波数。
- `SNR`: 付与ノイズの強度。
- `waterflow`: 水流音ノイズ。
- `whitenoise`: 白色雑音。
- `heatflux_no_noise`: ノイズなしの熱流束データ。

## 注意点

- `.npy` のファイル名先頭が教師ラベルになるため、リネームミスは学習結果に直結する。
- train/validation/testの分割単位が、同一実験条件や同一熱流束の重複をまたいでいないか確認する。
- ノイズ付与時は、信号とノイズの長さ合わせ、SNR計算、加算式を確認する。
- 画像として保存する場合、軸ラベルや余白が学習に混入しないか注意する。
