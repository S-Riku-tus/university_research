# 修論作業稿：背景・実験条件・評価設計・A〜Dの判断

作成日：2026-09-22。章構成は[修論構成案](../research_plan/2026-09-16_master_thesis_outline.md)に対応する。本文へ移す前の作業稿であり、装置諸元、先行研究の引用、正式なONB定義、提出日程は確認後に補う。

## 1. 研究背景と目的（第1章用）

プール沸騰では、核沸騰開始（ONB）付近から伝熱状態と発生音が変化する。本研究は、実験中に収録した音響信号の1秒スペクトログラムから熱流束を回帰し、その連続予測を所定のONB閾値と比較してONBを判定する。接触式計測を置き換えた実機検知までを直ちに主張するのではなく、実験日が変わる条件と水流雑音下で、推定性能がどこまで保たれるか、複数モデルの統合がどの条件で有効かを明らかにする。

修士研究で答える問いは三つである。第一に、学習日と評価日を分けたときに熱流束回帰とONB判定がどこまで成立するか。第二に、学習音から弱い区間を選別する処理が別日性能を改善するか。第三に、RF、CNN＋時間token Transformer、AlexNetの統合が雑音下の劣化を抑える条件と、その失敗理由を残差・帯域感度から説明できるかである。[中心仮説](../research_plan/2026-09-15_master_thesis_hypothesis.md)

## 2. 実験データと入力（第2章用）

現在の主比較は2025年6月11日を学習日、6月18日を評価日とする。各熱流束条件の元WAVを1秒へ分割し、6月18日の18 WAV×60秒=1080秒を選別せず評価する。音響入力は高域通過等の既存前処理後にSTFT powerスペクトログラムへ変換し、主条件では0〜22 kHzを224×224×1へ整形する。詳細な生成処理は[`2.run_npy_waterflow_2つhighpass.py`](../../code/2.run_npy_waterflow_2つhighpass.py)、データ対応は[データ索引](../data_inventory.md)へ遡る。

熱流束は元WAVごとの実験条件ラベルで、毎秒の気泡発生有無を示す正解ではない。同期した気泡観察映像と未使用の独立実験日は現時点でない。したがって、1秒ごとのONB判定はrunで設定した熱流束閾値に対する判定として扱い、気泡発生時刻の検出とは呼ばない。

## 3. モデル、分割、評価（第3章用）

単体モデルはPCA特徴を入力するXGBoost Random Forest回帰、log-powerスペクトログラムを入力するCNN＋時間token Transformer、AlexNet回帰である。統合は学習日内で元WAVを分離した`inner_holdout`性能から非負重みを求め、評価日前に固定する。学習日のPCA、scaler、モデル、統合重みのfitへ6月18日のラベルを使わない。

主な指標は全1080秒のR²、MAE、RMSE、run-ONB閾値±10%のRMSE、見逃し、誤警報である。秒を独立実験の反復数とみなさず、元WAV単位の二乗誤差とseed反復も併記する。ノイズ比較では各SNRで再学習する`matched`と、同じclean学習済みモデルを全SNRへ転送する`clean_only`を区別する。

run151715が使った6月18日のONB閾値は271,677.6816 W/m²である。一方、実験原記録には376,000 W/m²と記載され、定義が一致しない。run再現値での結果と376,000 W/m²の感度解析を区別し、物理的ONBの結論は教授との定義確認まで保留する。[Cの閾値監査](../../experiments/2026-09-20_c_selection/README.md)

## 4. 学習区間選別の結果（第4章用）

1e-9ピーク高さ選別の有無を、6/11学習、6/18全1080秒評価、22 kHz、無雑音、200 epochs、seed 42/43/44で対応比較した。選別は学習1080秒から94秒を除いた。統合R²の選別あり−なしは−.0035、+.0025、+.0016で符号がそろわなかった。run-ONB前の二乗誤差は全seedで減った一方、近傍1 WAVと近傍外ONB以上は全seedで悪化した。よって1e-9選別を主条件へ採用しない。現行の`inner_holdout`重みを運用基準として維持し、等重みと単体を固定対照として報告する。[C1〜C3結果](../../experiments/2026-09-20_c_selection/README.md)

この結果は、弱い学習区間を除けば一様に改善するという仮説を支持しない。選別は低熱流束の過大予測を抑えるが、ONB近傍・高熱流束の情報も失う可能性がある。また、run閾値で除外された94秒は原記録の6/11 ONB値369,000 W/m²よりすべて低く、選別対象の物理的な呼称も閾値定義に依存する。

## 5. ノイズ下の単体・統合結果（第5章用）

run151715のmatched学習では、統合R²が無雑音.9112、−8 dB .8261、−16 dB .8838、−20 dB .8756となり、−8 dBに谷があった。秒別診断では、−8 dBのCNN＋TransformerとAlexNetがONB前・近傍で同方向へ外れ、統合もRF単体に負けた。無雑音でもONB近傍はCNN＋Transformer単体より統合が悪く、重み付けで常に最良単体を保持できるわけではない。[A1〜A7](../../experiments/2026-09-19_noise_recovery_review/A1_A7_saved_prediction_diagnosis.md)

同じclean学習済みモデル・重みを固定した転送では、統合R²が無雑音.918、−8 dB .737、−16 dB .442、−20 dB .152と雑音強度に沿って悪化し、−8 dBの谷は消えた。matched −8対−16 dBの再学習をseed 42/43/44で反復したR²差は+.0305、−.0188、+.0147で符号が一致しなかった。このため谷を一般的な音響現象とはせず、SNR別再学習・重み・日差を含む不安定な現象として扱う。[B1〜B6](../../experiments/2026-09-19_b_clean_only/README.md)

## 6. 残差と説明性の判断（第6章用）

同一秒の残差分解では、異符号の単体誤差が相殺されて統合が改善する秒は存在した。一方、−8 dB全体では3モデルが同方向へ外れる交差項が大きく、統合で補完できない秒が支配的だった。説明性はこの残差事実を補助する目的で用い、地図だけから誤差原因を断定しない。

周波数帯ゼロマスクでは、AlexNetの1–2 kHz除去が無雑音・−8 dBの両方で極端な悪化を生じた。CNN＋Transformerの−8 dB 256–512 Hz除去は改善したが無雑音では悪化し、条件をまたぐ帯域改善ではなかった。ゼロ置換による分布変化も大きいため、現在は帯域保持・除去再学習へ進まない。[D1〜D3](../../experiments/2026-09-22_d_explainability/README.md)

TreeSHAPは10代表秒でRF予測を最大0.523 W/m²誤差で再構成でき、PCA空間での内部予測構成に使える。IGは無雑音・−8 dBの20枚中7枚だけが数値収束し、代替baselineも未検査なので主張から外す。AlexNetのGrad-CAMは最終畳み込み層の12×12正方向地図を拡大した補助図に限定し、細い周波数帯や物理的気泡音の根拠にしない。

## 主張と根拠の対応

| 現時点の主張 | 主要根拠 | 限界 |
|---|---|---|
| 別日6/18で回帰可能だが、ONB近傍には大きい見逃しが残る | run151715、A | ONB閾値定義が未確定、評価日は開発判断にも使用済み |
