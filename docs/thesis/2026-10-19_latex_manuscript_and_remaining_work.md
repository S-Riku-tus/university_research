## 研究の筋と章の分担

**ONB近傍の検知が目的 → 回帰を介して推定誤差と閾値判定を評価 → 固定モデルへの付加雑音とモデル統合を比較 → 全域・総見逃しの改善と発生段階の未達を示す → 誤差構造と入力依存から説明 → 現在言える結論と不足へ戻る。**

| 章 | 今回書いた内容 |
|---|---|
| 1 緒言 | 背景・確認した先行研究・回帰を使う理由・三つの研究質問。直接分類より優れるとは主張しない |
| 2 使用データと解析条件 | 既存データを使う立場，取得者・担当の未確認，ラベルの根拠，既知WAV内の1620/540分割 |
| 3 手法 | 生成manifestに基づくSTFT，実装に即した5モデルと34特徴，OOF重み，固定基準SNR，日別判定，q100，誤差分解 |
| 4 性能評価 | 同じ540区間の主表，全7条件，予測分布，FN/FP，日別q100，記録上ONB段階30区間の結果 |
| 5 要因分析・考察 | 領域別の交換，同方向誤差の縮小，判定の訂正・喪失，共通入力加工，特徴除去と配分の区別，物理解釈の限界 |
| 6 結言 | 目的に対応する五つの結論。全域改善，悪化量，開始段階の未達，誤差補完，入力依存を区別 |

主系列は10/15 clean_only `143609`，hash `da540f2d`，fit `7560205f8feb`。第4章の表を保存CSVから抽出し，図4点を保存表・予測から組版向けに作成した。第5章は10/14接続分析と10/7の完了済み入力対照へ根拠を分けている。新fit・モデル推論・音響加工・GPU処理は実施していない。

中心結論は「元3 MSEに対し全7条件の全域RMSEと総FNは改善するが，雑音による悪化量の縮小とONB発生段階の十分な検知は未達」。無雑音8/30，−20 dB 0/30を明記した。30区間は2 WAVからの抽出であり，独立した30回のONB発生実験とはしない。

## 不足を埋める順番

| 種別 | ID | 次に必要なこと |
|---|---|---|
| 原資料の確認 | D01–D05 | 取得者・提供元，著者等の担当，対象日の実験・収録条件，熱流束の算出，ONB判定の原根拠 |
| 再現資料 | D06 | 主実行時のソフトウェア・実行環境の版。現環境の版を過去の版として代用しない |
| 文献・考察 | L01–L02 | Dunlap/Barathula本文の分割・正解・雑音・ONB評価，手塚最終修論と対象条件の照合 |
| 任意の補助説明 | L03 | IGを追加する場合だけ，モデル・入力・基準・収束を揃える |
| 提出前の仕上げ | F01–F03 | 正式題目・提出様式，和英要旨，謝辞の本人確認 |
| 強い主張への条件 | V01–V04 | epochの最適性，未知日一般化，入力依存差の因果・物理音源，十分なONB早期検知を主張する場合の証拠 |

まずD01–D05と必要な文献を埋め，目的と現在の限定した結論が指導方針に合うかを相談する。その後，より強い結論が必要な箇所だけ追加比較を選ぶ。現在の未達を隠すために，目的を全域回帰の改善だけへ変更しない。未達があることから既存の比較成果まで無効とも扱わない。

## LaTeX環境と検証

既存の `LaTeX/sample/document.tex` は三上氏の別研究の発表用サンプルで，設定スライドも2023年の資料だった。今回の端末のPATHと一般的な設置先には既存TeX本体が見つからなかった。過去環境が削除されたとは断定せず，`LaTeX/master_thesis/` 内に独立した組版環境を用意した。

Tectonic 0.17.0（公式配布・archive SHA-256照合），bxjsreport，XeTeX，日本語原ノ味フォントを使用。実行ファイルとキャッシュは同ディレクトリ内の `.tools/`・`.cache/` に配置し，Git対象外とした。ユーザー全体のPATH・VS Code設定や研究用Python環境を変更していない。PDF読取用PyMuPDFは一時ディレクトリのみへ導入した。

`build.ps1` でPDF作成成功。`scripts/check_manuscript.py --pdf` で，6章，引用19件，図表・数式参照，16個の不足ID，出典hash，主要数値，PDFの文字取得・ページ範囲を点検した。最終結果は[検証JSON](../../LaTeX/master_thesis/build/validation.json)に保存する。全ページを縮小一覧で確認し，表紙・本文・主表・考察・結論・不足欄の代表ページを拡大確認した。過去PDF，スライド，データ，学習済みモデルは保持した。
