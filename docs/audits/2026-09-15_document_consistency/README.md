## 確認範囲

開始時に322文書（Markdown 103、PDF 113、Word 61、PowerPoint 45）を列挙し、SHA-256と本文抽出結果を保存した。320件で本文を抽出、2件は画像中心・文字量不足、抽出処理エラーは0件。抽出した約164万文字を対象に、古い進捗・研究上の主張・手法・次の作業の候補を検索し、現行方針に関係する記述を照合した。

全件の本文検索と、研究方針に関係する原資料・記述の照合である。全PDF・スライドの全図を目視で再読したものではなく、引用論文の全内容を科学的に再検証したものでもない。画像中心の次の2件は先頭ページを目視確認し、本文を確認できた資料としては数えない。

- `研究進捗報告/2025/12月12日（中間発表）/CNN_Ensemble_Learning_Acoustic_Detection_Pool_Boiling.pdf`（14ページ）：表紙の発表日は2025年7月18日で配置先の日付とは異なる。
- `研究進捗報告/原子力機構_三上_1.pdf`（13ページ）：Na炉の音響診断の参考資料。自研究の水によるプール沸騰の検証結果と区別する。

生成データ・学習結果の巨大な保存階層 `Pool_boiling/`、`.git`、ログ、キャッシュ、本監査自身は文書本文棚卸しの対象外。特に本人が対象外とした進行中runを監視・採用していない。YAMLは実験条件の記録であり、上記322件の本文件数には含めない。

## 改訂した判断

| 観点 | 修正した問題 | 現在の扱い |
|---|---|---|
| 研究の中心 | アンサンブルが最後に回す付加課題に見える | 学部の劣化抑制を発展させ、成立条件と理由を調べる中心仮説とする |
| 仮説と事実 | 希望する単調低下を全条件で得る前提 | 3 kHzの部分的支持、22 kHzの補完と非単調性、RFの横ばいを併記する |
| 比較対象 | 22 kHz単独のSOAP、未統合とする案内 | 完了済み06.11・各7ノイズの2帯域比較へ統一する |
| 指標 | 小さい劣化量を、そのまま高い耐性・ONB改善と読む | 無雑音基準・強ノイズ絶対性能・ONB誤りを分ける |
| 原因 | 旧データのshortcutを現行結果へ適用する | 固定global RMS後の帯域SNR・resize・WAV誤差分布を手がかりとし、内部原因は未確定とする |
| 説明性 | 採用・画像出力と、信頼性検証の混同 | 各手法の説明対象、IGの不整合、共通マスクの分布変化、物理解釈の限界を分ける |
| 周波数解釈 | resize後のHz/画素を物理的な周波数分解能と読む | 元STFTの刻みと画像化の補間・縮小を区別する |
| 次の作業 | 新実験が終わるまで既存データ比較を待つ順序 | 代表条件の再現性・転送・原因比較と、新ONB実験の準備を並行する案にする |
| 履歴 | 古い未着手・RF優位・手法候補を現行指示として使う | 当時の本文を保ち、適用時点と後継資料を明示する |

新しい解析の実行や、効果が得られる条件の選別を今回の文書整理で行ったものではない。今後の比較順は作業案であり、研究上の結論や実行済みの事項ではない。
