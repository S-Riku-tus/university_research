# 論文輪講スライド構成案（テンプレート）

> **使い方**：このファイルをコピーして `研究進捗報告/<年>/<回>（論文輪講）/スライド構成案.md` を作り、`〔　〕` を埋める。
> **体裁ルールと全体構成（4セクション＋中扉）は基本そのまま使い、内容だけ差し替える**こと。手法セクションの枚数だけ論文に合わせて伸縮させる。
> 作成手順は `AGENTS.md`「論文輪講を作るとき」を参照。完成した構成案を、直近の論文輪講pptx（例: `研究進捗報告/2026/501（論文輪講）/`）にコピー流用して仕上げる。

対象論文：**〔正式タイトル ── 論文 p.1 の実題と完全一致させる。略称があれば（XXX）と併記〕** ── 〔著者, arXiv/DOI〕

---

## 体裁（部品）の使い分け ★最重要

| 部品 | 使いどころ |
| --- | --- |
| リード文（太字1文） | ヘッダー直下。そのスライドの結論を一言で |
| ▌縦バー見出し | 背景／目的／新規性／定義… 1枚に複数可 |
| ⚫主箇条書き＋➢サブ | 流れ・定義・列挙。**並列比較でないもの** |
| ➡／⬇ 矢印 | 論理の帰結・流れ。先にハイライト文を置く |
| 角丸ボックス（淡ティール） | 強調1文（目的）／結果スライド下部のまとめ |
| 比較表（ティール濃ヘッダ） | **複数手法の利点/課題など並列比較**のみ |

> **鉄則：表は「複数手法を同じ観点で並べて比べる」ときだけ。**
> 論文を選んだ理由・背景・目的・新規性・手法の流れ・**用語/語の定義**・まとめは、表ではなく **箇条書き（▌＋⚫＋➢＋連番＋➡）** にする。
> （手法名の語分解のような用語定義も「比較」ではないので表にしない。）

## 図の方針 ★

> **図は原則として論文中の図（Fig./Table）を使い、自作はしない。**
> 1. まず該当する論文の図を割り当てる（貼る前に実PDFで図番号・内容・図/表の別を確認）。
> 2. 手法ステップなど専用図が無い場合は、**全体図（Fig.◯）を再掲し該当部分を拡大/ハイライト**する（同一図の段階的提示）。
> 3. それでも該当が無ければ **図なし**（箇条書き・式ボックス・矢印で説明）。背景やIG等の基礎説明は図なしで成立する。
> 4. 自作は最終手段。使う場合のみ本文に「自作」と明記する。

## 式の方針 ★

> **数式は論文中の式をそのまま使い、論文の式番号「式(N)」を必ず併記する。**（自分で式を作らない／番号をぼかさない）
> 手法スライドでは該当する式を式ボックスに置き、記号の意味を⚫で1–2行補足。末尾に「式の対応表」を作り、式番号→内容→使うスライドを一覧化する。

## 全体構成（標準22枚／中扉4枚込み）

```
01 論文を選んだ理由        : 1 タイトル / 2 Agenda / 3[中扉] / 4 論文を選んだ理由
02 研究背景・目的          : 5[中扉] / 6 研究背景 / 7 既存手法の課題 / 8 目的・新規性
03 手法                    : 9[中扉] / 10 全体像 / 11 基礎(既存手法) / 12-15 各Step / 16 実験設定
04 結果・結論              : 17[中扉] / 18 結果① / 19 結果② / 20 結果③ / 21 限界 / 22 まとめ・活用
```

> 手法セクション（12〜15あたり）は **論文の手法ステップ数に合わせて増減**してよい。
> 結果も論文の評価軸の数に合わせる。中扉4枚・Agenda・タイトルは固定。

軸となるメッセージ（1本通す）：
> 〔例：「既存手法では○○が見えない → △△で見る → 提案手法で□□まで見る → 自分の沸騰音研究にどう使うか」〕

## スライド12〜15：手法 – Step1〜StepN

> 各Stepを1枚ずつ。**レイアウト＝図左＋箇条書き右型**で統一。論文のステップ数に合わせて枚数調整。

各スライド共通フォーマット：
- **リード文**：**〔そのStepの一言〕**
- **本文**：`▌何をするか` → `▌計算（論文 式(N)）`＋式ボックス → `⚫式の読み（記号の意味・正負など）` → `▌他手法との違い/意味` → `➡帰結`
- **式**：そのStepに対応する**論文の式を式番号「式(N)」つきで式ボックスに記載**し、記号の意味を⚫で1–2行補足。どの式かを必ず明示（口頭でも「論文の式(N)」と言う）。式は自作しない。
- **図**：**全体図（Fig.◯）の該当ステップ部分を拡大/ハイライト**して使う。専用の論文図があればそれを優先。自作はしない。
- **話す内容**：〔そのStepの語り。次Stepへの接続を最後に〕
- **体裁メモ**：核心となるStep（融合・統合など）には「★核心」と付け、リード文で強調。正負/2値の対比など**2項の並列だけは小さな比較表**にしてよい。手法スライドは全体図を再掲し該当Stageをハイライトする「同一図の段階的提示」で統一すると分かりやすい。
